 $ 2x^2 + 2xy + y^2 - 2x + 1 = 0 \Leftrightarrow x^2 + 2xy + y^2 + x^2 - 2x + 1 = 0 \Leftrightarrow (x + y)^2 + (x - 1)^2 = 0 $ ②，

因为  $ (x + y)^2 \geq 0 $， $ (x - 1)^2 \geq 0 $，所以结合②可得  $ x + y = 0 $ 且  $ x - 1 = 0 $，解得： $ x = 1 $， $ y = -1 $，

所以该方程表示的图形为点（1）。

【反思】判断方程表示的图形是否为圆时，可先观察该方程的形式，若  $ x^2 $ 与  $ y^2 $ 的系数不同，或含有交叉项  $ xy $，则可快速得出该方程不表示圆；若该方程的形式符合  $ x^2 + y^2 + Dx + Ey + F = 0 $，则再比较  $ D^2 + E^2 - 4F $ 与 0 的大小，按知识点 2 得出结论。反之，对于含参的关于  $ x $， $ y $ 的二元二次方程，若题干已给出方程表示圆，则也可由  $ x^2 + y^2 + Dx + Ey + F = 0 $ 的形式及  $ D^2 + E^2 - 4F > 0 $ 确定参数满足的条件，我们来看两个变式。

【变式1】若方程 $ x^{2}+y^{2}-2ax+2ay+2a^{2}+a+1=0 $表示圆，则实数a的取值范围是（）

A. $ (-1,+\infty) $ B. $ (-\infty,-1] $ C. $ (-\infty,-1) $ D. $ [-1,+\infty) $

解析：在所给方程中，D = -2a，E = 2a， $ F = 2a^2 + a + 1 $，该方程表示圆，所以 $ D^2 + E^2 - 4F = (-2a)^2 + (2a)^2 - 4(2a^2 + a + 1) = -4(a + 1) > 0 $，解得：a < -1，所以实数 $ a $的取值范围是 $ (-\infty, -1) $。

答案：C

【变式2】已知 $ 2a^{2}x^{2}+(a+1)y^{2}+2x+1=0 $表示圆，则实数a的值为（）

A. -1 B. 1 C.  $ \frac{1}{2} $ D.  $ -\frac{1}{2} $

解析：观察发现  $ x^2 $ 和  $ y^2 $ 的系数含参，而已知方程的图形表示圆，所以可利用两系数相等建立方程，由  $ 2a^2x^2 + (a+1)y^2 + 2x + 1 = 0 $ 表示圆可知  $ 2a^2 = a + 1 $，解得： $ a = 1 $ 或  $ -\frac{1}{2} $， $ x^2 $ 和  $ y^2 $ 的系数相等的方程都表示圆吗？显然不是，还需检验  $ D^2 + E^2 - 4F > 0 $ 是否成立，当  $ a = 1 $ 时，代回原方程得  $ 2x^2 + 2y^2 + 2x + 1 = 0 $，即  $ x^2 + y^2 + x + \frac{1}{2} = 0 $，所以  $ D = 1 $， $ E = 0 $， $ F = \frac{1}{2} $，从而  $ D^2 + E^2 - 4F = 1^2 + 0^2 - 4 \times \frac{1}{2} = -1 < 0 $，故原方程不能表示圆，不合题意；
