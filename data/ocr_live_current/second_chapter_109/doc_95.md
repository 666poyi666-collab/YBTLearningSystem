解析：判断两圆的位置关系，先计算圆心距，再与半径的和、差进行比较，

 $ x^2 + y^2 - 4 = 0 \Leftrightarrow x^2 + y^2 = 4 $，所以圆  $ C_1 $ 的圆心为  $ C_1(0,0) $，半径  $ r_1 = 2 $，

 $ x^2 + y^2 - 4x + 4y - 8 = 0 \Leftrightarrow (x - 2)^2 + (y + 2)^2 = 16 $，所以圆  $ C_2 $ 的圆心为  $ C_2(2, -2) $，半径  $ r_2 = 4 $，

所以圆心距  $ d = |C_1C_2| = \sqrt{(2 - 0)^2 + (-2 - 0)^2} = 2\sqrt{2} $，

又  $ r_1 + r_2 = 2 + 4 = 6 $， $ |r_1 - r_2| = 2 $，所以  $ |r_1 - r_2| < d < r_1 + r_2 $，故圆  $ C_1 $ 与圆  $ C_2 $ 相交。

答案：C

【反思】判断两圆的位置关系，只需计算圆心距，再将其与半径的和以及差的绝对值比较大小。两圆的位置关系与两圆公切线的条数一一对应，所以两圆的位置关系也可以公切线条数的形式考查，比如下面的变式1，2。

【变式1】圆 $ C_1:(x-1)^2+(y-1)^2=2 $与圆 $ C_2:x^2-2ax+y^2+2(a-2)y=4a-4 $（ $ a<0 $）的公切线条数为（ ）

解析：公切线条数由两圆的位置关系决定，故先判断两圆的位置关系，

由题意， $ C_1(1,1) $， $ r_1 = \sqrt{2} $， $ x^2 - 2ax + y^2 + 2(a-2)y = 4a - 4 \Leftrightarrow (x-a)^2 + (y+a-2)^2 = 2a^2 $，

因为  $ a < 0 $，所以  $ C_2(a,2-a) $， $ r_2 = -\sqrt{2}a $，圆  $ C_1 $ 和圆  $ C_2 $ 的圆心距  $ d = |C_1C_2| = \sqrt{(a-1)^2 + (2-a-1)^2} = \sqrt{2}|a-1| $，

结合  $ a < 0 $ 可得  $ d = \sqrt{2}|a-1| = \sqrt{2}(1-a) $，因为  $ r_1 + r_2 = \sqrt{2} + (-\sqrt{2}a) = \sqrt{2}(1-a) $，所以  $ d = r_1 + r_2 $，

从而圆  $ C_1 $ 与圆  $ C_2 $ 外切，故两圆有 3 条公切线。

答案：C

【反思】两圆的位置关系与两圆公切线的条数是一一对应的（结论见知识点3），既可以通过两圆的位置关系得到两圆的公切线条数，也可以通过两圆公切线条数反推两圆的位置关系。
