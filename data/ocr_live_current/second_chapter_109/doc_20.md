那“ $ l_1 \parallel l_2 $”的充要条件是“ $ m = -4 $或1”吗？务必注意，当 $ k_1 = k_2 $时， $ l_1 $与 $ l_2 $还可能重合，故需检验；当 $ m = -4 $时， $ l_1: 6x + 3y + 1 = 0 $， $ l_2: 4x + 2y - 1 = 0 $，两直线不重合，满足 $ l_1 \parallel l_2 $；当 $ m = 1 $时， $ l_1: x + 3y + 1 = 0 $， $ l_2: x + 3y + 1 = 0 $，两直线重合，不满足 $ l_1 \parallel l_2 $；综上所述，“ $ m = -4 $”是“ $ l_1 \parallel l_2 $”的充要条件。

答案：C

【反思】当条件给出两直线平行，让求参数的值时，可由 $ k_{1}=k_{2} $建立方程求参，但别忘了考虑两直线斜率都不存在的情况，以及检验求出的参数是否会使得两直线重合。类似的，涉及两直线垂直时，也可按 $ k_{1}k_{2}=-1 $建立方程求参，我们来看下面的变式。

【变式】已知直线 $ l_1:2x+ay+1=0 $， $ l_2:ax+(1-a)y-2=0 $，若 $ l_1\perp l_2 $，则实数 $ a $的值为___

解析：涉及两直线垂直，可按 $ k_1k_2=-1 $建立方程求 $ a $，下面先考虑有直线斜率不存在的特殊情况，

当 $ l_1 $的斜率不存在时， $ a=0 $，此时 $ l_1 $的方程为 $ x=-\frac{1}{2} $， $ l_2 $的方程为 $ y=2 $，满足 $ l_1\perp l_2 $；

当 $ l_1 $的斜率存在时， $ a\neq0 $，此时 $ l_1 $的方程可化为 $ y=-\frac{2}{a}x-\frac{1}{a} $，所以其斜率 $ k_1=-\frac{2}{a}\neq0 $，

从而要使 $ l_1\perp l_2 $，则 $ l_2 $的斜率必须存在，故 $ 1-a\neq0\Rightarrow a\neq1 $，此时 $ l_2 $的方程可化为 $ y=\frac{a}{a-1}x-\frac{2}{a-1} $，

所以其斜率 $ k_2=\frac{a}{a-1} $，因为 $ l_1\perp l_2 $，所以 $ k_1k_2=-\frac{2}{a}\cdot\frac{a}{a-1}=-1 $，解得： $ a=3 $；

综上所述，实数 $ a $的值为0或3。

答案：0 或 3

## 补充、拓展

这一节我们补充寻找直线所过的定点这个题型，它在高中数学解析几何的后续内容中比较常见，这里我们先带大家认识直线过定点的概念.

类型V：寻找直线所过的定点

【例 15】设  $ a \in \mathbb{R} $，则直线  $ l: (a+1)x + (2-a)y - a = 0 $ 所过的定点是___。

解析：当 a 变化时，直线的方程会变，由于方程中有 3 个 a，所以不易看出方程的变化规律，但观察发现参数 a 都是一次的，故可将这几项单独集中到一起，把 a 提出来，以便于看出规律，

由题意，直线 l 的方程可化为  $ ax + x + 2y - ay - a = 0 $，即  $ a(x - y - 1) + (x + 2y) = 0 $ ①，

怎样由式①寻找 $l$ 所过的定点？$l$ 过定点意味着无论 $a$ 如何取值，该点的坐标都满足方程①，仔细观察会发现，只要让式①中的 $x-y-1$ 为 $0$，$a(x-y-1)$ 这部分就不受 $a$ 的变化的影响了，那为了让式①成立，余下的 $x+2y$ 也应为 $0$，由此可找到直线 $l$ 所过的定点，

令 $\begin{cases} x-y-1=0 \\ x+2y=0 \end{cases}$ 可得 $x=\frac{2}{3}$，$y=-\frac{1}{3}$，所以当 $x=\frac{2}{3}$，$y=-\frac{1}{3}$ 时，对任意的 $a\in\mathbf{R}$，方程①都成立，

故直线 $l$ 所过的定点是 $\left(\frac{2}{3},-\frac{1}{3}\right)$。

答案： $ \left(\frac{2}{3},-\frac{1}{3}\right) $

【反思】寻找含参直线所过的定点时，我们常将含参的部分拿到一起，化为形如  $ af(x,y)+g(x,y)=0 $ 的结构，再令  $ \begin{cases} f(x,y)=0 \\ g(x,y)=0 \end{cases} $，解出 x 和 y，即可找到直线所过的定点。直线过定点有较多应用，我们先来看两个变式。
