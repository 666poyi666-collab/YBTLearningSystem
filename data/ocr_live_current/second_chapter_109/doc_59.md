当 $ a = -\frac{1}{2} $时，代回原方程得 $ \frac{1}{2}x^2 + \frac{1}{2}y^2 + 2x + 1 = 0 $，即 $ x^2 + y^2 + 4x + 2 = 0 $，所以 $ D = 4 $， $ E = 0 $， $ F = 2 $，从而 $ D^2 + E^2 - 4F = 4^2 + 0^2 - 4 \times 2 = 8 > 0 $，故原方程表示圆，满足题意；

综上所述，实数 $ a $的值为 $ -\frac{1}{2} $。

答案：D

【反思】对于根据方程表示圆求参这类题，由圆的一般方程的系数特征建立方程求出参数后，一定要代回原方程，并将其严格化为一般方程 $ x^2 + y^2 + Dx + Ey + F = 0 $的形式，再检验 $ D^2 + E^2 - 4F > 0 $是否成立。
