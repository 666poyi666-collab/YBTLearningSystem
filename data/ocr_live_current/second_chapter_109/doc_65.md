## 补充、拓展

当直线的方程含参时，直线会随着参数取值的改变而变化，但直线可能过定点，那如果圆的方程中含参，它是否也可能过定点呢？我们通过下面的类型Ⅶ来给大家拓展这类题的处理方法.

## 类型Ⅶ：圆过定点问题

【例 11】圆  $ C: x^{2} + y^{2} + ax - 2ay - 5 = 0 $ 恒过的定点为（ ）

A.  $ (-2,1) $,  $ (2,-1) $ B.  $ (-1,-2) $,  $ (2,1) $ C.  $ (-1,-2) $,  $ (1,2) $ D.  $ (-2,-1) $,  $ (2,1) $

解析：与寻找含参直线所经过定点原理类似，要找圆所过的定点，我们也先把方程中含参的部分整合到一起，由题意，圆  $ C $ 的方程可化为  $ x^2 + y^2 - 5 + a(x - 2y) = 0 $ ①，

要使某特定的  $ x $， $ y $ 总能满足方程①，不受  $ a $ 的影响，只能  $ x - 2y = 0 $，于是剩下的  $ x^3 + y^2 - 5 $ 也等于 0，由此可建立方程组求  $ x $， $ y $，找到圆  $ C $ 过的定点，令  $ \begin{cases} x - 2y = 0 \textcircled{2} \\ x^2 + y^2 - 5 = 0 \textcircled{3} \end{cases} $，由②得  $ x = 2y $，代入③解得： $ y = \pm 1 $，

当  $ y = 1 $ 时， $ x = 2y = 2 $；当  $ y = -1 $ 时， $ x = 2y = -2 $，所以圆  $ C $ 经过定点  $ (2,1) $ 和  $ (-2,-1) $。

答案：D

【反思】寻找含参曲线所经过的定点，常将曲线方程中含参的部分整合到一起，提出参数，化为形如  $ f(x,y) + a \cdot g(x,y) = 0 $ 的形式，由  $ \begin{cases} f(x,y) = 0 \\ g(x,y) = 0 \end{cases} $ 求解 x, y，得到定点坐标。本题圆的方程是直接给出的，若要增加题目的综合性，可以设置为先求圆的方程，再寻找定点，我们来看一个变式。

【变式】在平面直角坐标系 xOy 中，曲线  $ \Gamma: y = x^2 - mx + 2m (m \in \mathbb{R}) $ 与 x 轴交于不同的两点  $ A $， $ B $，曲线  $ \Gamma $ 与 y 轴交于点  $ C $。

（1）是否存在以线段 AB 为直径的圆过点 C？若存在，求出该圆的方程；若不存在，请说明理由；

（2）试确定．过 A，B，C 三点的圆是否过定点.

（2）试确定：过A，B，C三点的圆是否过定点.

解：（1）解法1：（怎样翻译以AB为直径的圆过点C？要先求圆的方程，再将点C代入吗？这样做较麻烦，注意到以AB为直径的圆经过点C意味着 $ AC \perp BC $，而翻译 $ AC \perp BC $，可考虑用 $ k_{AC}k_{BC} = -1 $， $ \overrightarrow{AC} \cdot \overrightarrow{BC} = 0 $，或 $ |CG| = \frac{1}{2}|AB| $（其中G为AB中点）。本题若选第一个方法，则需单独考虑AC，BC斜率不存在和C与A或B重合的情况，而后两个方法则可统一处理，我们先试试第二个翻译方法）

在 $ y = x^2 - mx + 2m $中令x=0得 $ y=2m $，所以 $ C(0,2m) $，令 $ y=0 $得 $ x^2 - mx + 2m=0 $①，（此方程不方便求解，怎么办呢？若无思路，可先设出A，B的坐标，表示出 $ \overrightarrow{AC} \cdot \overrightarrow{BC} $，再作观察）

设 $ A(x_1,0) $， $ B(x_2,0) $，则 $ \overrightarrow{AC} = (-x_1,2m) $， $ \overrightarrow{BC} = (-x_2,2m) $，所以 $ \overrightarrow{AC} \cdot \overrightarrow{BC} = (-x_1)(-x_2) + (2m)^2 = x_1x_2 + 4m^2 $，

 $$ C\Leftrightarrow\overrightarrow{AC}\cdot\overrightarrow{BC}=0\Leftrightarrow x_{1}x_{2}+4m^{2}=0 $$ 

（可发现只需将  $ x_1x_2 $ 用  $ m $ 表示，代入②，就能得到只含  $ m $ 的方程，怎样表示  $ x_1x_2 $？注意到  $ x_1 $， $ x_2 $ 是曲线  $ \Gamma $ 与  $ x $ 轴交点的横坐标，它们应为方程①的两个实根，故可用韦达定理计算  $ x_1x_2 $）

对方程①，判别式  $ \Delta = (-m)^2 - 4 \times 1 \times 2m = m^2 - 8m > 0 $，解得： $ m < 0 $ 或  $ m > 8 $，

由韦达定理， $ x_1x_2 = 2m $，代入②得  $ 2m + 4m^2 = 0 $，解得： $ m = -\frac{1}{2} $ 或  $ 0 $（舍去），

（于是满足题意的圆存在，怎样求其方程？需要圆心坐标 $ \left(\frac{x_1+x_2}{2},0\right) $和半径 $ r=\frac{1}{2}\left|AB\right|=\frac{1}{2}\left|x_1-x_2\right| $，它们可由韦达定理及其推论计算，故又按此分别计算这两个量）
