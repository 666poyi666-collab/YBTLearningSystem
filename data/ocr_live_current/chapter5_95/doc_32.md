# 补充、拓展

相信通过上面的学习，大家已经对用导数研究函数的方法比较熟悉了，有时我们也会遇到题干给出导数有关的条件，让求解一些与原函数有关的问题，此时就需要我们由所给的导数条件去构造原函数，这是求导的逆运算，我们通过下面的类型VI来给大家总结一些常见的模型。

## 类型VI：构造原函数

【例 10】若函数  $ f(x) $ 及其导函数  $ f'(x) $ 的定义域均为  $ \mathbb{R} $，且  $ f'(x) > 3 $，则关于  $ x $ 的不等式  $ f(x) - f(1-x) \leq 6x - 3 $ 的解集为（ ）

A.  $ [1, +\infty) $  

B.  $ \left[\frac{1}{2}, +\infty\right) $  

C.  $ (-\infty, 1] $  

D.  $ \left(-\infty, \frac{1}{2}\right] $

解析：没有解析式，要求解目标不等式，当然考虑单调性，如何分析单调性？条件给出  $ f'(x) > 3 $，用它能研究哪个函数的单调性？该不等式可化为  $ f'(x) - 3 > 0 $，谁求导后等于  $ f'(x) - 3 $？其中  $ f'(x) $ 是由  $ f(x) $ 求导而来，那一呢？这部分可由  $ -3x $ 求导得来，于是应构造函数  $ f(x) - 3x $ 来分析，思路就有了，设  $ g(x) = f(x) - 3x $，则由题意， $ g'(x) = f'(x) - 3 > 0 $，所以  $ g(x) $ 在  $ \mathbb{R} $ 上  $ \nearrow $，既然有了  $ g(x) $ 的单调性，当然考虑把要解的不等式化为  $ g(x) $ 的形式， $ f(x) - f(1 - x) \leq 6x - 3 \Leftrightarrow f(x) \leq f(1 - x) + 6x - 3 \Leftrightarrow f(x) - 3x \leq f(1 - x) + 3x - 3 \Leftrightarrow f(x) - 3x \leq f(1 - x) - 3(1 - x) \Leftrightarrow g(x) \leq g(1 - x) $，结合  $ g(x) $ 在  $ \mathbb{R} $ 上  $ \nearrow $ 可得  $ x \leq 1 - x $，解得： $ x \leq \frac{1}{2} $。

答案：D

【反思】若给出的含 $ f'(x) $的不等式各部分都容易看出原函数，则直接移项到同一侧，构造原函数即可，我们再通过两个变式来巩固一下。

【变式 1】设函数  $ f(x) $， $ g(x) $ 在  $ [a,b] $ 上的导函数分别为  $ f'(x) $， $ g'(x) $，且  $ f'(x) > g'(x) $， $ f(a) = g(a) $，则当  $ x \in (a,b) $ 时，下列不等式中一定成立的是（ ）

A.  $ f(x) + g(x) > 0 $  B.  $ f(x) < g(x) $  C.  $ f(x) > g(x) $  D.  $ f(x) + g(x) < 0 $

解析： $ f'(x) $ 和  $ g'(x) $ 的原函数分别为  $ f(x) $ 和  $ g(x) $，所以直接将  $ f'(x) > g'(x) $ 移项，就能构造原函数分析，当  $ x \in [a,b] $ 时，由  $ f'(x) > g'(x) $ 得  $ f'(x) - g'(x) > 0 $，令  $ F(x) = f(x) - g(x) $， $ x \in [a,b] $，则  $ F'(x) = f'(x) - g'(x) > 0 $，所以  $ F(x) $ 在  $ [a,b] $ 上  $ \nearrow $，又因为  $ f(a) = g(a) $，所以  $ F(a) = f(a) - g(a) = 0 $，故当  $ x \in (a,b) $ 时， $ F(x) > F(a) = 0 $，即  $ f(x) - g(x) > 0 $，所以  $ f(x) > g(x) $。

答案：C
