【例2】若不等式 $ ae^{x}-\ln x-1\geq0 $恒成立，求实数a的取值范围.

解法1：（所给不等式中的参数 $a$ 只出现一次，容易分离到不等号的一侧，故考虑先将其分离出来，再作分析）

因为 $a\mathrm{e}^x - \ln x - 1 \geq 0$，所以 $a\mathrm{e}^x \geq 1 + \ln x$，故 $a \geq \frac{1 + \ln x}{e^x}$ ①，

（于是 $a \geq \left( \frac{1 + \ln x}{e^x} \right)_{\max}$，$\frac{1 + \ln x}{e^x}$ 不算复杂，要求其最大值，可尝试构造函数求导分析）

令 $f(x) = \frac{1 + \ln x}{e^x}$，$x > 0$，则 $f'(x) = \frac{\frac{1}{x} e^x - e^x (1 + \ln x)}{(e^x)^2} = \frac{\frac{1}{x} - 1 - \ln x}{e^x}$，

（观察发现 $f'(1) = 0$，故可尝试分析 $f'(x)$ 在 $x=1$ 两侧的正负）

当 $0 < x < 1$ 时，$\frac{1}{x} - 1 > 0$，$\ln x < 0$，所以 $\frac{1}{x} - 1 - \ln x > 0$，故 $f'(x) > 0$；

当 $x > 1$ 时，$\frac{1}{x} - 1 < 0$，$\ln x > 0$，所以 $\frac{1}{x} - 1 - \ln x < 0$，故 $f'(x) < 0$，

所以 $f(x)$ 在 $(0,1)$ 上单调递增，在 $(1,+\infty)$ 上单调递减，所以 $f(x)_{\max} = f(1) = \frac{1}{e}$，

由①知 $a \geq f(x)$ 恒成立，所以 $a \geq \frac{1}{e}$，故实数 $a$ 的取值范围是 $\left[ \frac{1}{e}, +\infty \right)$。

解法2：（按解法1得到不等式①，并求出$f'(x)$后，若没发现可直接判断$f'(x)$在$x=1$两侧的正负，也可考虑继续求导分析，直接求导显然比较复杂，注意到$f'(x)$分母的$e^x$始终为正，故可将分子单独拿出来求导分析）

令$g(x)=\frac{1}{x}-1-\ln x$，$x>0$，则$g'(x)=-\frac{1}{x^2}-\frac{1}{x}<0$，所以$g(x)$在$(0,+\infty)$上单调递减，

又$g(1)=0$，所以当$0<x<1$时，$g(x)>0$，故$f'(x)>0$，当$x>1$时，$g(x)<0$，所以$f'(x)<0$，下同解法1.

【反思】在含参不等式问题中，若参数能够分离出来，且参变分离后的函数不复杂，容易分析最值，则可考虑

参变分离，本题参变分离后的函数比较简单，如果参变分离后的函数比较复杂，那么计算量可能就偏大，但此

法思维量较小，所以也值得尝试，比如下面的变式. 当然，有的情况参变分离后确实不好研究，此时还有另外

两种常见的处理方法，后面我们会接着举例.

【变式】已知函数  $ f(x)=\frac{x^{2}}{e^{x}} $

（1）求  $ f(x) $ 的单调区间；

（2）当 $ x\geq1 $时， $ f(x)+k(1+\ln x)\leq0 $，求实数k的取值范围.

解：（1）由题意， $ f'(x)=\frac{2xe^x - e^x \cdot x^2}{(e^x)^2} = \frac{(2 - x)x}{e^x} $，所以  $ f'(x) > 0 \Leftrightarrow 0 < x < 2 $， $ f'(x) < 0 \Leftrightarrow x < 0 $ 或  $ x > 2 $，故  $ f(x) $ 的单调递增区间是  $ (0, 2) $，单调递减区间是  $ (-\infty, 0) $， $ (2, +\infty) $。

（2）（观察发现参数 k 只出现一次，且当  $ x \geq 1 $ 时， $ 1 + \ln x > 0 $，故容易从所给不等式中分离出 k，可尝试将 k 分离出来再看）当  $ x \geq 1 $ 时， $ f(x) + k(1 + \ln x) \leq 0 \Leftrightarrow \frac{x^2}{e^x} + k(1 + \ln x) \leq 0 \Leftrightarrow k(1 + \ln x) \leq -\frac{x^2}{e^x} \Leftrightarrow k \leq -\frac{x^2}{e^x(1 + \ln x)} $ ①，（于是  $ k \leq \left[-\frac{x^2}{e^x(1 + \ln x)}\right]_{mm} $，要求  $ -\frac{x^2}{e^x(1 + \ln x)} $ 的最小值，可尝试先构造函数，求导分析单调性）

设  $ g(x) = -\frac{x^2}{e^x(1 + \ln x)} $， $ x \geq 1 $，则  $ g'(x) = -\frac{2xe^x(1 + \ln x) - x^2}{[e^x(1 + \ln x)]^2} = -\frac{x[2(1 + \ln x) - x(1 + \ln x) - 1]}{e^x(1 + \ln x)^2} $，

（不易直接判断正负，考虑继续求导，直接求导显然很复杂，注意到分子的  $ x $ 和分母的  $ e^x(1 + \ln x)^2 $ 恒为正数，

于是  $ g'(x) $ 的正负与  $ 2(1 + \ln x) - x(1 + \ln x) - 1 $ 相反，故可将这部分单独拿出来求导分析）
