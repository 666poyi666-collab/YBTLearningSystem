 $$ =a\cdot\frac{1}{a}-\frac{1}{\frac{1}{a}}+(a+1)\ln a-2=(a+1)\ln a-a-1； $$ 

当 $a=1$ 时，$f'(x)=\frac{(\mathrm{e}^x-1)^2}{\mathrm{e}^x}\geq0$，当且仅当 $x=0$ 时取等号，所以 $f(x)$ 在 $\mathbb{R}$ 上单调递增，故 $f(x)$ 无极值；

当 $a>1$ 时，$0<\frac{1}{a}<1$，$\ln\frac{1}{a}<0$，所以 $f'(x)>0\Leftrightarrow(\mathrm{e}^x-1)\left(\mathrm{e}^x-\frac{1}{a}\right)>0\Leftrightarrow\mathrm{e}^x<\frac{1}{a}$ 或 $\mathrm{e}^x>1\Leftrightarrow x<\ln\frac{1}{a}$ 或 $x>0$，

同理，$f'(x)<0\Leftrightarrow\ln\frac{1}{a}<x<0$，所以 $f(x)$ 在 $\left(-\infty,\ln\frac{1}{a}\right)$ 上单调递增，在 $\left(\ln\frac{1}{a},0\right)$ 上单调递减，

在 $(0,+\infty)$ 上单调递增，故 $f(x)$ 有极大值 $f\left(\ln\frac{1}{a}\right)=(a+1)\ln a-a-1$，极小值 $f(0)=a-3$。

【反思】可以看到，求含参函数的极值，其核心是讨论函数的单调性，这类问题在上一节我们已经详细归纳过了，所以这里我们只举两道例题.

## 类型Ⅲ：根据极值点或极值求参

【例 7】已知  $ f(x) = \ln x + ax - b $， $ a, b \in \mathbb{R} $，若函数  $ f(x) $ 在  $ x=1 $ 处取得极大值 0，则  $ a + b = $ ___。

解析：取得极值的必要条件是导数为 0，所以已知条件可翻译为  $ \begin{cases} f'(1) = 0 \\ f(1) = 0 \end{cases} $，由此可建立方程组求 a 和 b，

由题意， $ f'(x) = \frac{1}{x} + a $，因为  $ f(x) $ 在 x = 1 处取得极大值 0，所以  $ \begin{cases} f'(1) = 1 + a = 0 \\ f(1) = a - b = 0 \end{cases} $，解得：a = b = -1，

作为填空题，因为只有一组解，所以可以直接由此得到  $ a + b = -2 $。但需注意， $ f'(1) = 0 $ 只是  $ f(x) $ 在 x = 1 处取得极值的必要条件，而且不一定是极大值，故若为解答题，则需检验，下面我们把检验的过程也给出来，

此时  $ f'(x) = \frac{1}{x} - 1 = \frac{1 - x}{x} (x > 0) $，所以  $ f'(x) > 0 \Leftrightarrow 0 < x < 1 $， $ f'(x) < 0 \Leftrightarrow x > 1 $，

从而  $ f(x) $ 在  $ (0,1) $ 上  $ \nearrow $，在  $ (1,+\infty) $ 上  $ \searrow $，满足  $ f(x) $ 在 x = 1 处取得极大值，故  $ a + b = -1 + (-1) = -2 $。

答案：-2

【反思】当条件给出函数  $ f(x) $ 在  $ x = x_{0} $ 处取得极值时，可尝试由  $ f'(x_{0}) = 0 $ 建立方程求参。但需注意，求出参数后，别忘了检验  $ f(x_{0}) $ 是否真的是极值。有时我们还会遇到  $ f'(x_{0}) = 0 $ 恒成立，无法由此求出参数的情况，此时又怎么办呢？我们来看下面的变式。

(i) 当  $ k \leq 0 $ 时， $ e^x - k > 0 $，所以  $ f'(x) > 0 \Leftrightarrow x > 1 $， $ f'(x) < 0 \Leftrightarrow x < 1 $，

从而  $ f(x) $ 在  $ (-∞,1) $ 上单调递减，在  $ (1,+∞) $ 上单调递增，故 x=1 是  $ f(x) $ 的极小值点，满足题意；

（再看 k > 0 的情况，此时  $ f'(x) $ 有零点 1 和  $ \ln k $，它们的大小关系不确定，且该大小关系对  $ f'(x) $ 在各段上的正负情况有影响，故又讨论 1 与  $ \ln k $ 的大小，即讨论 k 与 e 的大小。由于  $ e^x - k $ 与  $ x - \ln k $ 的正负一致，于是  $ f'(x) $ 与  $ (x - 1)(x - \ln k) $ 的正负也一致，故可将  $ f'(x) $ 等效成  $ (x - 1)(x - \ln k) $ 来看，这样  $ f'(x) $ 的正负就容易判断了）
