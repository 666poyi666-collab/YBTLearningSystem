证法2：（按证法1得到只需证 $ 2\mathrm{e}^a - a^2 \geq 2a + 2 $后，注意到有 $ \mathrm{e}^a $这一结构，而对任意的函数 $ \varphi(a) $，都有 $ \left[\frac{\varphi(a)}{\mathrm{e}^a}\right] = \frac{\varphi'(a) - \varphi(a)}{\mathrm{e}^a} $，其正负与 $ \varphi'(a) - \varphi(a) $相同，可不再考虑 $ \mathrm{e}^a $，这意味着可将 $ 2\mathrm{e}^a - a^2 \geq 2a + 2 $进一步转化为 $ \frac{a^2 + 2a + 2}{\mathrm{e}^a} \leq 2 $来证，也许能简化求导分析的过程）

要证  $ f(a) \geq 2a + 2 $，只需证  $ 2\mathrm{e}^a - a^2 \geq 2a + 2 $，即证  $ 2\mathrm{e}^a \geq a^2 + 2a + 2 $，也即证  $ \frac{a^2 + 2a + 2}{\mathrm{e}^a} \leq 2 $ ①，

令  $ h(a) = \frac{a^2 + 2a + 2}{\mathrm{e}^a} $， $ a \geq 0 $，则  $ h'(a) = \frac{(2a + 2)\mathrm{e}^a - \mathrm{e}^a(a^2 + 2a + 2)}{(\mathrm{e}^a)^2} = -\frac{a^2}{\mathrm{e}^a} \leq 0 $，所以  $ h(a) $ 在  $ [0, +\infty) $ 上单调递减，

又  $ h(0) = \frac{0^2 + 2 \times 0 + 2}{\mathrm{e}^0} = 2 $，所以  $ h(a) \leq 2 $，即  $ \frac{a^2 + 2a + 2}{\mathrm{e}^a} \leq 2 $，从而不等式①成立，故  $ f(a) \geq 2a + 2 $ 成立。

【反思】尽管两种证法都证出了不等式，但和证法1相比，证法2可少求一次导，所以当不等式中有 $ e^x $时，可考虑将其调整为 $ \frac{\varphi(x)}{e^x} $或 $ e^x\varphi(x) $这种结构，再证明，很多时候会更简单（但也有例外，比如后面的变式3）。

【变式2】证明不等式：

证法1：（要证的不等式结构不算复杂，可尝试直接移项，构造函数求导分析）

设  $ f(x)=\left(1-\frac{2}{x}\right)\ln x+\frac{1}{2} $， $ x>0 $，则  $ f'(x)=\frac{2}{x^2}\ln x+\left(1-\frac{2}{x}\right)\frac{1}{x}=\frac{2\ln x+x-2}{x^2} $，

（不易直接判断正负，考虑继续求导，但可想象，若直接求导，则会变得很复杂，怎么办呢？注意到分母的 $ x^2 $始终为正，于是 $ f'(x) $的正负仅由分子决定，故可考虑把分子单独拿出来求导分析）设 $ g(x)=2\ln x+x-2 $， $ x>0 $，则 $ g'(x)=\frac{2}{x}+1>0 $，所以 $ g(x) $在 $ (0,+\infty) $上单调递增，

（有了 $ g(x) \nearrow $，则 $ g(x) $的零点即为其正负分界点，但经尝试，此处零点无法求出，怎么办呢？像这种零点不可求的情况，可考虑虚设零点，再用它来继续分析）

因为 $ g(1) = -1 < 0 $， $ g(2) = 2\ln 2 > 0 $，所以 $ g(x) $在 $ (0, +\infty) $上有唯一的零点，设为 $ x_0 $，则 $ 1 < x_0 < 2 $，

当 $ 0 < x < x_0 $时， $ g(x) < 0 $，所以 $ f'(x) < 0 $， $ f(x) $在 $ (0, x_0) $上单调递减，

当 $ x > x_0 $时， $ g(x) > 0 $，所以 $ f'(x) > 0 $， $ f(x) $在 $ (x_0, +\infty) $上单调递增，所以 $ f(x)_{\min} = f(x_0) = \left(1 - \frac{2}{x_0}\right)\ln x_0 + \frac{1}{2} $ ①，

（要证结论成立，只需证 $ f(x_0) > 0 $，显然直接由式①无法看出正负，怎么办呢？注意到 $ x_0 $是 $ g(x) $的零点，于是有 $ g(x_0) = 0 $，可尝试利用这一层关系化简式①，再判断正负）

因为 $ g(x_0) = 2\ln x_0 + x_0 - 2 = 0 $，所以 $ \ln x_0 = \frac{2 - x_0}{2} $，代入①得 $ f(x_0) = \left(1 - \frac{2}{x_0}\right)\frac{2 - x_0}{2} + \frac{1}{2} = \frac{5}{2} - \frac{1}{2}\left(x_0 + \frac{4}{x_0}\right) $，

由 $ 1 < x_0 < 2 $知 $ 4 < x_0 + \frac{4}{x_0} < 5 $，所以 $ f(x_0) > 0 $，从而 $ f(x) > 0 $，故不等式 $ \left(1 - \frac{2}{x}\right)\ln x > -\frac{1}{2} $成立。

证法2：（证法1思维量较大，有无其它方法？可以想象，对任意的函数 $ \varphi(x) $，都有 $ [\ln x+\varphi(x)]'=\frac{1}{x}+\varphi'(x) $，所以若能将要证的不等式中的 $ \ln x $与 $ 1-\frac{2}{x} $分开，孤立出 $ \ln x $，则求导后就不再含有 $ \ln x $了，可能会更好分析，故按此尝试.注意到当 $ 1-\frac{2}{x} $与 $ \ln x $同号时，结论显然成立，于是我们先单独分析同号的这两种情况）当 $ 0<x\leq1 $时， $ 1-\frac{2}{x}<0 $， $ \ln x\leq0 $，所以 $ \left(1-\frac{2}{x}\right)\ln x\geq0>-\frac{1}{2} $，原不等式成立；
