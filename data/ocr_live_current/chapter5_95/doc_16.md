A.  $ f'(1)=0 $ B. 4 是  $ f(x) $ 的一个周期

C.  $ f(100)=0 $ D.  $ f(x) $ 的图象关于点 (2,1) 对称

解析：A 项，条件给出  $ f(x+1) $ 为偶函数，我们先将它翻译出来，再看如何求  $ f'(1) $，

由题意，记  $ g(x)=f(x+1) $ 为偶函数，则  $ g(x) $ 为偶函数，所以  $ g(-x)=g(x) $，即  $ f(-x+1)=f(x+1) $ ①，

目标涉及  $ f'(1) $，故考虑将上式求导，由①可得  $ -f'(-x+1)=f'(x+1) $，

令 x=0 得  $ -f'(1)=f'(1) $，所以  $ f'(1)=0 $，故 A 项正确；

B 项，要推导  $ f(x) $ 的周期，考虑找  $ f(x) $ 的对称性，于是我们先把  $ f'(x) $ 为偶函数翻译为  $ f(x) $ 的对称性，因为  $ f'(x) $ 为偶函数，所以  $ f'(-x) = f'(x) $，怎样把此式翻译成关于  $ f(x) $ 的性质？哪个式子求导后能得到  $ f'(-x) = f'(x) $？由于  $ [-f(-x)]' = f'(-x) $，所以  $ -f(-x) = f(x) $ 求导后能得到  $ f'(-x) = f'(x) $，但请注意，常数求导结果为 0，所以加个常数，不影响求导的结果，于是可修正为  $ -f(-x) + C = f(x) $，

由  $ f'(-x) = f'(x) $ 可得  $ -f(-x) + C = f(x) $，所以  $ f(-x) + f(x) = C $，故  $ f(x) $ 关于点  $ \left(0, \frac{C}{2}\right) $ 对称，

又由①可知  $ f(x) $ 关于直线 x = 1 对称，所以  $ f(x) $ 是周期函数，周期  $ T = 4|1 - 0| = 4 $，故 B 项正确；

C 项，因为  $ f(x) $ 周期为 4，所以  $ f(100) = f(0 + 25 \times 4) = f(0) $ ②，

经尝试，仅由①无法求出  $ f(0) $，考虑结合  $ f'(x) $ 为偶函数推理，怎么推？已由该条件得到  $ f(-x) + f(x) = C $，若能求出  $ C $，就能通过取 x = 0 求出  $ f(0) $，怎样求  $ C $? 条件还给出了  $ f(-1) + f(1) = 2 $，故考虑由它求  $ C $，在  $ f(-x) + f(x) = C $ 中令 x = 1 得  $ f(-1) + f(1) = C $，结合  $ f(-1) + f(1) = 2 $ 可得 C = 2，所以  $ f(-x) + f(x) = 2 $ ③，令 x = 0 得  $ f(0) + f(0) = 2 $，所以  $ f(0) = 1 $，代入②得  $ f(100) = 1 \neq 0 $，故 C 项错误；

D 项，结论等价于  $ f(-x) + f(4 + x) = 2 $，观察发现这与式③很像，故考虑由式③出发推理，因为  $ f(x) $ 的周期为 4，所以  $ f(x) = f(x + 4) $，代入③得  $ f(-x) + f(x + 4) - 2 = 0 $，

所以  $ f(-x) + f(x + 4) = 2 $，从而  $ f(x) $ 关于点  $ (2,1) $ 对称，故 D 项正确。

答案：ABD

【反思】由导函数的奇偶性推原函数的奇偶性，其结论及推导方法是：①若  $ f'(x) $ 为奇函数，则  $ f'(-x) = -f'(x) $，所以  $ -f(-x) = -f(x) + C $，从而  $ f(-x) = f(x) - C $，取 x = 0 可得 C = 0，所以  $ f(-x) = f(x) $，故  $ f(x) $ 为偶函数；②若  $ f'(x) $ 为偶函数，则  $ f'(-x) = f'(x) $，所以  $ -f(-x) + C = f(x) $，从而  $ f(-x) + f(x) = C $，故  $ f(x) $ 关于  $ \left(0, \frac{C}{2}\right) $ 对称，此时  $ f(x) $ 不一定为奇函数，还要看 C 是否等于 0.
