当$x \geq 2$时，$1 - \frac{2}{x} \geq 0$，$\ln x > 0$，所以$\left(1 - \frac{2}{x}\right)\ln x \geq 0 > -\frac{1}{2}$，原不等式成立；

（最后来看$1 < x < 2$的情形，此时$1 - \frac{2}{x} < 0$，可将要证的不等式两端同除以$1 - \frac{2}{x}$，将$\ln x$孤立出来）

当$1 < x < 2$时，$1 - \frac{2}{x} < 0$，要证$\left(1 - \frac{2}{x}\right)\ln x > -\frac{1}{2}$，只需证$\ln x < -\frac{x}{2(x-2)}$，即证$\ln x + \frac{x}{2(x-2)} < 0$，

设$h(x) = \ln x + \frac{x}{2(x-2)}$，$1 < x < 2$，则$h'(x) = \frac{1}{x} + \frac{x - 2 - x}{2(x-2)^2} = \frac{1}{x} - \frac{1}{(x-2)^2} = \frac{(x-1)(x-4)}{x(x-2)^2} < 0$，

所以$h(x)$在$(1,2)$上单调递减，结合$h(1) = -\frac{1}{2} < 0$知$h(x) < 0$，即$\ln x + \frac{x}{2(x-2)} < 0$，故原不等式成立；

综上所述，不等式$\left(1 - \frac{2}{x}\right)\ln x > -\frac{1}{2}$对任意的$x > 0$成立。

【反思】①导函数的零点不可求是一种常见的情况，此时一种考虑的方向是虚设出该零点，由此出发分析单调性，求得函数的最值，再运用该零点来化简最值，这种处理方法我们常称之为“隐零点的零点代换”，在后续小节中，我们还会反复用到这种方法；②尽管两种证法都证出了不等式，但证法2显然更简便，所以当要证的不等式中有 $ u(x)\ln x $这种结构时，可以考虑将其等价变形成 $ \ln x + \varphi(x) $的形式，再构造函数证明.

【变式 3】已知函数  $ f(x) = e^{2x} - mx $， $ m \leq 2 $，证明：当  $ x \geq 0 $ 时， $ f(x) \geq \cos x $。

证明：要证  $ f(x) \geq \cos x $，即证  $ \mathrm{e}^{2x} - mx \geq \cos x $，也即证  $ \mathrm{e}^{2x} - mx - \cos x \geq 0 $ ①，

（此不等式中含有参数 $m$，直接构造函数求导分析较麻烦，注意到条件给出了 $m \leq 2$，故可考虑用它将不等式①的左侧进行放缩，转化为不含参的不等式来证）

因为 $m \leq 2$，$x \geq 0$，所以 $mx \leq 2x$，故 $\mathrm{e}^{2x} - mx - \cos x \geq \mathrm{e}^{2x} - 2x - \cos x$ ②，

（故要证不等式①成立，只需证 $\mathrm{e}^{2x} - 2x - \cos x \geq 0$，接下来可构造函数求导分析）

令 $g(x) = \mathrm{e}^{2x} - 2x - \cos x$，$x \geq 0$，则 $g'(x) = 2\mathrm{e}^{2x} - 2 + \sin x$，

（不易直接判断正负，考虑继续求导）所以 $ g''(x)=4\mathrm{e}^{2x}+\cos x\geq4+\cos x\geq4-1=3>0 $，

从而 $ g'(x) $在 $ [0,+\infty) $上单调递增，故 $ g'(x)\geq g'(0)=2\mathrm{e}^{2\times0}-2+\sin0=0 $，所以 $ g(x) $在 $ [0,+\infty) $上单调递增，

又因为 $ g(0)=\mathrm{e}^{2\times0}-2\times0-\cos0=0 $，所以 $ g(x)\geq0 $，即 $ \mathrm{e}^{2x}-2x-\cos x\geq0 $，结合②可得 $ \mathrm{e}^{2x}-mx-\cos x\geq0 $。

所以 $ \mathrm{e}^{2x}-mx\geq\cos x $，即 $ f(x)\geq\cos x $。

【反思】①若要证的不等式中含参，但给出了参数的范围，则可利用该范围来放缩，转化为不含参的不等式证明；②本题得到只需证 $ e^{2x} - 2x - \cos x \geq 0 $后，若转化为证 $ \frac{2x + \cos x}{e^{2x}} \leq 1 $，则反而会比直接求导分析更麻烦（请读者自行尝试），所以遇到 $ e^x $这种结构，可以考虑向 $ \varphi(x)e^x $或 $ \frac{\varphi(x)}{e^x} $转化，但不一定每次这样做都更简单。
