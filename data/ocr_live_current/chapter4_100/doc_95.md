因为  $ a_n a_{n+1} = 3^n $，所以  $ a_n \ne 0 (n \in \mathbf{N}^* $)，且当  $ n \ge 2 $ 时， $ a_{n-1} a_n = 3^{n-1} $，两式相除得  $ \frac{a_n a_{n+1}}{a_{n-1} a_n} = \frac{3}{3^{n-1}} $，故  $ \frac{a_{n+1}}{a_{n-1}} = 3 $，

（由上式能得到什么？若无思路，可以代一些值进去看看，分别取  $ n = 2, 3, 4, 5 $ 得  $ \begin{cases} \frac{a_3}{a_1} = 3, \frac{a_5}{a_3} = 3, \cdots \\ \frac{a_4}{a_2} = 3, \frac{a_6}{a_4} = 3, \cdots \end{cases} $，于是  $ \{a_n\} $ 的奇数项、偶数项分别构成公比为 3 的等比数列，故应分奇偶分别求通项）

当  $ n $ 为奇数时，设  $ n = 2k - 1 (k \in \mathbf{N}^* $)，则  $ k = \frac{n+1}{2} $， $ a_n = a_{2k-1} = a_1 \cdot 3^{k-1} = 1 \times 3^{k-1} = 3^{k-1} = 3^{\frac{n+1}{2}} = 3^{\frac{n-1}{2}} $；

（再看  $ n $ 为偶数时的情形，要像上面这样类似地计算吗？不用，题干给出  $ a_n a_{n+1} = 3^n $，用它来算比较简单）

当  $ n $ 为偶数时， $ n+1 $ 为奇数，所以  $ a_{n+1} = 3^{\frac{n+1-1}{2}} = 3^{\frac{n}{2}} $，又  $ a_n a_{n+1} = 3^n $，所以  $ a_n = \frac{3^n}{a_{n+1}} = \frac{3^n}{3^2} = 3^{\frac{n}{2}} $；

综上所述， $ a_n = \begin{cases} 3^{\frac{n-1}{2}}, & n \text{为奇数} \\ 3^{\frac{n}{2}}, & n \text{为偶数} \end{cases} $。

【反思】像  $ a_n a_{n+1} = f(n) $ 这种递推公式，可退 n 得到  $ a_{n-1} a_n = f(n-1) $，两式相除得  $ \frac{a_{n+1}}{a_{n-1}} = \frac{f(n)}{f(n-1)} $，进而分奇偶讨论。

## 类型IV：放缩法证明数列求和不等式

【例 5】已知  $ \{a_n\} $ 是正项数列， $ S_n $ 为  $ \{\sqrt{a_n}\} $ 的前  $ n $ 项和，且  $ \sqrt{a_n} $， $ S_n $， $ a_n-2 $ 成等差数列.

（1）求 $ \{a_{n}\} $的通项公式；

（2）求证： $ \frac{1}{a_{1}}+\frac{1}{a_{2}}+\frac{1}{a_{3}}+\cdots+\frac{1}{a_{n}}<\frac{3}{4} $

解：（1）由题意， $ \sqrt{a_n} $， $ S_n $， $ a_n-2 $ 成等差数列，所以 $ 2S_n=\sqrt{a_n}+a_n-2 $ ①，

（得到了 $ a_n $与 $ S_n $混搭的关系式，要求的是 $ a_n $，故考虑退 $ n $相减，消去 $ S_n $，但请注意，这里 $ S_n $是数列 $ \{\sqrt{a_n}\} $的前 $ n $项和，不是数列 $ \{a_n\} $的前 $ n $项和，所以 $ S_n-S_{n-1}=\sqrt{a_n} $）

所以当 $ n\geq2 $时， $ 2S_{n-1}=\sqrt{a_{n-1}}+a_{n-1}-2 $，从而 $ 2S_n-2S_{n-1}=\sqrt{a_n}+a_n-2-\sqrt{a_{n-1}}-a_{n-1}+2 $，

故 $ 2\sqrt{a_n}=\sqrt{a_n}+a_n-\sqrt{a_{n-1}}-a_{n-1} $，化简得： $ a_n-a_{n-1}-(\sqrt{a_n}+\sqrt{a_{n-1}})=0 $，

所以 $ (\sqrt{a_n}+\sqrt{a_{n-1}})(\sqrt{a_n}-\sqrt{a_{n-1}})-(\sqrt{a_n}+\sqrt{a_{n-1}})=0 $，故 $ (\sqrt{a_n}+\sqrt{a_{n-1}})(\sqrt{a_n}-\sqrt{a_{n-1}}-1)=0 $ ②，

又因为 $ \{a_n\} $是正项数列，所以 $ \sqrt{a_n}+\sqrt{a_{n-1}}>0 $，从而式②可化为 $ \sqrt{a_n}-\sqrt{a_{n-1}}-1=0 $，故 $ \sqrt{a_n}-\sqrt{a_{n-1}}=1 $，

在①中取 $ n=1 $得 $ 2S_1=\sqrt{a_1}+a_1-2 $，结合 $ S_1=\sqrt{a_1} $可得 $ 2\sqrt{a_1}=\sqrt{a_1}+a_1-2 $，所以 $ a_1-\sqrt{a_1}-2=0 $，

从而 $ (\sqrt{a_1}-2)(\sqrt{a_1}+1)=0 $，解得： $ \sqrt{a_1}=2 $，故 $ \{\sqrt{a_n}\} $是首项为2，公差为1的等差数列，

所以 $ \sqrt{a_n}=2+(n-1)\times1=n+1 $，故 $ a_n=(n+1)^2 $。
