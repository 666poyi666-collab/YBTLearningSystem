【变式3】已知等差数列 $ \{a_{n}\} $的前n项和为 $ S_{n} $，若 $ a_{1}=15 $， $ S_{7}=14a_{10} $，则

(1)  $ a_{11} + a_{12} + \cdots + a_{20} =  $___；(2)  $ a_2 + a_5 + a_8 + \cdots + a_{35} =  $___。

解析：（1）已知  $ a_1 $，所以代公式翻译  $ S_7 = 14a_{10} $ 可建立关于  $ d $ 的方程，求出公差  $ d $，

设  $ \{a_n\} $ 的公差为  $ d $，由  $ S_7 = 14a_{10} $ 得  $ 7a_1 + \frac{7 \times 6}{2}d = 14(a_1 + 9d) $，所以  $ 7 \times 15 + 21d = 14(15 + 9d) $，解得： $ d = -1 $，

怎样求  $ a_{11} + a_{12} + \cdots + a_{20} $？由于  $ a_{11} $， $ a_{12} $， $ \cdots $， $ a_{20} $ 也成等差数列，故可代公式计算，怎么代？事实上，对于公式  $ S_n = \frac{n(a_1 + a_n)}{2} = na_1 + \frac{n(n-1)}{2}d $，可解读为  $ S_n = \frac{\text{项数} \times (\text{首项} + \text{末项})}{2} = \text{项数} \times \text{首项} + \frac{\text{项数} \times (\text{项数} - 1)}{2} \times \text{公差} $。具体到这里，由于是求  $ a_{11} + a_{12} + \cdots + a_{20} $，所以首项变成了  $ a_{11} $，末项则为  $ a_{20} $，项数为 10，代公式的方法就有了， $ a_{11} + a_{12} + \cdots + a_{20} = \frac{10 \times (a_{11} + a_{20})}{2} = 5(a_{11} + a_{20}) = 5(a_1 + 10d + a_1 + 19d) = 5(2a_1 + 29d) = 5[2 \times 15 + 29 \times (-1)] = 5 $；

再求  $ a_2 + a_5 + a_8 + \cdots + a_{35} $，注意到下标 2，5，8， $ \cdots $，35 是等差数列，所以  $ a_2 $， $ a_5 $， $ a_8 $， $ \cdots $， $ a_{35} $ 也构成等差数列，可仿照第一空的方法代公式来求  $ a_2 + a_5 + a_8 + \cdots + a_{35} $，首项和末项好求，那项数呢？数列 2，5，8， $ \cdots $，35 的通项公式为  $ 3n - 1 $，令  $ 3n - 1 = 35 $ 可解出  $ n = 12 $，所以共有 12 项，

因为  $ a_n = a_1 + (n - 1)d = 15 + (n - 1) \cdot (-1) = 16 - n $，所以  $ a_2 = 16 - 2 = 14 $， $ a_{35} = 16 - 35 = -19 $，

故  $ a_2 + a_5 + a_8 + \cdots + a_{35} = \frac{12 \times (a_2 + a_{35})}{2} = \frac{12 \times (14 - 19)}{2} = -30 $。

答案：5；-30
