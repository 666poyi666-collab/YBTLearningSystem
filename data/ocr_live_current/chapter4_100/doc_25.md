【变式 1】若等差数列 $\{a_n\}$ 中，$a_1 + a_8 = 2a_5 - 2$，$a_3 + a_{11} = 26$，则数列 $\{a_n\}$ 的通项公式 $a_n = $___

解析：两个条件均为与项有关的等式，可用通项公式来翻译它们，建立关于 $a_1$ 和 $d$ 的方程组，

设等差数列 $\{a_n\}$ 的公差为 $d$，由题意，$\begin{cases} a_1 + a_8 = 2a_5 - 2 \\ a_3 + a_{11} = 26 \end{cases}$，所以 $\begin{cases} a_1 + a_1 + 7d = 2(a_1 + 4d) - 2 \\ a_1 + 2d + a_1 + 10d = 26 \end{cases}$，解得：$\begin{cases} a_1 = 1 \\ d = 2 \end{cases}$，

所以数列 $\{a_n\}$ 的通项公式为 $a_n = a_1 + (n-1)d = 1 + (n-1) \times 2 = 2n - 1$。

答案：2n-1

【变式2】在等差数列 $ \{a_{n}\} $中， $ a_{1}+a_{5}+a_{12}=15 $，则 $ a_{6}= $（）

A. 8 B. 7 C. 6 D. 5

解析：可以想象，题干只给了 1 个方程，用通项公式翻译它后，无法求出  $ a_1 $ 和  $ d $ 两个未知数，怎么办呢？可考虑将已知条件和所求都用基本量  $ a_1 $ 和  $ d $ 表示，观察它们的联系，

设等差数列  $ \{a_n\} $ 的公差为  $ d $，则由题意， $ a_1 + a_5 + a_{12} = 15 $，所以  $ a_1 + a_1 + 4d + a_1 + 11d = 15 \Rightarrow a_1 + 5d = 5 $，

又因为  $ a_6 = a_1 + 5d $，所以  $ a_6 = 5 $。

答案：D

【变式3】已知等差数列-2，1，4，7，10，⋯，现在其每相邻两项之间插入一个数，使之成为一个新的等差数列 $ \{a_{n}\} $，则数列 $ \{a_{n}\} $的第13项为___.

解析：已知  $ a_1 $，要求  $ a_{13} $，只缺公差  $ d $，如何求  $ d $？由插入的规则可知  $ a_3=1 $，用  $ a_1 $ 和  $ a_3 $ 两项就能求出  $ d $，由题意， $ a_1=-2 $， $ a_3=1 $，所以  $ \{a_n\} $ 的公差  $ d=\frac{a_3-a_1}{3-1}=\frac{1-(-2)}{2}=\frac{3}{2} $，所以  $ a_{13}=a_1+12d=-2+12\times\frac{3}{2}=16 $。

答案：16

## 类型Ⅲ：等差数列通项性质的应用

【例 10】已知 $ \{a_n\} $为等差数列，若 $ m, n, p, q $是正整数，则“ $ m + n = p + q $”是“ $ a_m + a_n = a_p + a_q $”的（ ）

A. 充分不必要条件

B. 必要不充分条件

C. 充要条件

D. 既不充分也不必要条件

解析： $ a_m + a_n = a_p + a_q $ 容易用公式翻译，进而化为  $ m $， $ n $， $ p $， $ q $ 的关系，故先翻译，再判断选项。

设  $ \{a_n\} $ 的公差为  $ d $，则  $ a_m + a_n = a_p + a_q \Leftrightarrow a_1 + (m-1)d + a_1 + (n-1)d = a_1 + (p-1)d + a_1 + (q-1)d \Leftrightarrow (m+n-2)d = (p+q-2)d \Leftrightarrow m+n-2 = p+q-2 $ 或  $ d=0 \Leftrightarrow m+n=p+q $ 或  $ d=0 $，所以 “ $ m+n=p+q $” 是 “ $ a_m + a_n = a_p + a_q $” 的充分不必要条件。

答案：A

【反思】本题是对知识点5中的性质②的证明，这个结论的考查频率很高。在等差数列问题中，当出现下标之和相同的条件时，往往可以利用该结论快速求解，我们来看几个变式。
