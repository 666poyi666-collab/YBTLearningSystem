当$n \geq 2$时，$b_{n+1} - b_n = \frac{n+1}{2(n+1)+1} - \frac{n}{2n+1} = \frac{n+1}{2n+3} - \frac{n}{2n+1} = \frac{(n+1)(2n+1) - n(2n+3)}{(2n+3)(2n+1)} = \frac{1}{(2n+3)(2n+1)} > 0$，

所以$\{b_n\}$从第$2$项起是单调递增的数列，故当$n \geq 2$时，$b_n \geq b_2 = \frac{2}{5}$，又$b_1 = 2 > b_2$，所以$\{b_n\}$的最小项为$\frac{2}{5}$，（最大项呢？由于$n \geq 2$时$\{b_n\}$为单调递增数列，所以只需判断$b_1$与$b_n$（$n \geq 2$）的大小关系）

当$n \geq 2$时，$b_n = \frac{n}{2n+1} < \frac{n}{2n} = \frac{1}{2} < 2 = b_1$，所以$\{b_n\}$的最大项为$2$。

【反思】先让证明某数列为等差数列，再求通项这类题，其实是通过要证明的结论来提示我们该如何去构造等差数列，那我们按前面类型Ⅰ的方法去证明即可。有时题干不会给出这种提示，这就需要我们自己找到构造的方法，我们来看两个变式。

【变式1】已知数列$\{a_n\}$满足$a_1=2$，且$a_{n+1}=3a_n-3^{n+1}(n\in\mathbb{N}^*)$，求$a_n$。

解：（题干没有提示我们该如何构造，怎么办呢？构造新数列的核心是凑出同一数列的前后项，怎么凑？注意到左边为  $ a_{n+1} $，右边为  $ 3a_n $，可两端同除以  $ 3^{n+1} $，这样左边化为  $ \frac{a_{n+1}}{3^{n+1}} $，右边的  $ 3a_n $ 则变成  $ \frac{a_n}{3^n} $，前后项就产生了）因为  $ a_{n+1} = 3a_n - 3^{n+1} $，所以  $ \frac{a_{n+1}}{3^{n+1}} = \frac{3a_n}{3^{n+1}} - \frac{3^{n+1}}{3^{n+1}} $，化简得： $ \frac{a_{n+1}}{3^{n+1}} = \frac{a_n}{3^n} - 1 $，所以  $ \frac{a_{n+1}}{3^{n+1}} - \frac{a_n}{3^n} = -1 $ ①，（将  $ \frac{a_n}{3^n} $ 看作一个整体，记作  $ b_n $，则式①即为  $ b_{n+1} - b_n = -1 $，说明  $ \{b_n\} $ 为等差数列，可先求出  $ b_n $，再求  $ a_n $）令  $ b_n = \frac{a_n}{3^n} $，则  $ b_1 = \frac{a_1}{3^1} = \frac{2}{3} $，由①得  $ b_{n+1} - b_n = -1 $，所以  $ \{b_n\} $ 是首项为  $ \frac{2}{3} $，公差为 -1 的等差数列，从而  $ b_n = \frac{2}{3} + (n-1) \cdot (-1) = \frac{5}{3} - n $，故  $ a_n = 3^n b_n = \left(\frac{5}{3} - n\right) 3^n $。

【反思】遇到形如  $ a_{n+1} = \lambda a_n + \lambda^n $ ( $ \lambda \neq 1, \lambda \neq 0 $) 的递推公式，可两端同除以  $ \lambda^{n+1} $，得到  $ \frac{a_{n+1}}{\lambda^{n+1}} = \frac{a_n}{\lambda^n} + \frac{1}{\lambda} $，则  $ \frac{a_{n+1}}{\lambda^{n+1}} - \frac{a_n}{\lambda^n} = \frac{1}{\lambda} $，所以  $ \left\{\frac{a_n}{\lambda^n}\right\} $ 是等差数列，进而可求得其通项，得到  $ a_n $。

【变式2】已知数列$\{a_n\}$各项均为正数，$a_1=1$，$a_{n+1}=\sqrt{S_{n+1}}+\sqrt{S_n}$。

（1）求 $ \{a_{n}\} $的通项公式；

（2）设 $ b_{n}=\frac{a_{n+1}}{S_{n}\cdot S_{n+1}} $，数列 $ \{b_{n}\} $的前n项和为 $ T_{n} $，证明： $ \frac{3}{4}\leq T_{n}<1 $。

解：（1）（条件给出 $a_n$ 与 $S_n$ 混搭的关系式，尽管让求的是 $a_n$，但可以想象，所给关系式中同时有 $\sqrt{S_{n+1}}$ 和 $\sqrt{S_n}$ 不方便通过退 $n$ 相减消去 $S_{n+1}$ 和 $S_n$，怎么办呢？可考虑将 $a_{n+1}$ 换成 $S_{n+1} - S_n$，消去 $a_{n+1}$）

由题意， $\{a_n\}$ 的各项均为正数，所以 $S_n > 0$ 对任意的 $n \in \mathbb{N}^*$ 都成立，

将 $a_{n+1} = S_{n+1} - S_n$ 代入 $a_{n+1} = \sqrt{S_{n+1}} + \sqrt{S_n}$ 得 $S_{n+1} - S_n = \sqrt{S_{n+1}} + \sqrt{S_n}$，

所以 $(\sqrt{S_{n+1}} + \sqrt{S_n})(\sqrt{S_{n+1}} - \sqrt{S_n}) = \sqrt{S_{n+1}} + \sqrt{S_n}$，又因为 $\sqrt{S_{n+1}} + \sqrt{S_n} > 0$，所以上式可化为 $\sqrt{S_{n+1}} - \sqrt{S_n} = 1$，

结合 $\sqrt{S_1} = \sqrt{a_1} = 1$ 可得 $\{\sqrt{S_n}\}$ 是首项和公差均为 1 的等差数列，所以 $\sqrt{S_n} = 1 + (n-1) = n$，故 $S_n = n^2$，

（已有 $S_n$，可利用 $a_n = S_n - S_{n-1}$ ($n \geq 2$) 求出 $a_n$）当 $n \geq 2$ 时，$a_n = S_n - S_{n-1} = n^2 - (n-1)^2 = 2n - 1$，

又因为 $a_n = 1$ 也满足 $a = 2n - 1$，所以对任意的 $n \in \mathbb{N}^*$，都有 $a_n = 2n - 1$。

（2）由（1）得  $ a_n = 2n - 1 $， $ S_n = n^2 $，所以  $ b_n = \frac{a_{n+1}}{S_n \cdot S_{n+1}} = \frac{2n+1}{n^2(n+1)^2} $，（注意到分母的  $ n^2 $ 和  $ (n+1)^2 $ 恰为前后项关系，于是想到裂项。经尝试， $ \frac{2n+1}{n^2(n+1)^2} = \frac{1}{n^2} - \frac{1}{(n+1)^2} $，按此可求出  $ T_n $，再作观察）
