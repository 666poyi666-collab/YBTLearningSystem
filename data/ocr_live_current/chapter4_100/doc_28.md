因为 $ b_n = \frac{2n+1}{n^2(n+1)^2} = \frac{1}{n^2} - \frac{1}{(n+1)^2} $，所以 $ T_n = b_1 + b_2 + \cdots + b_n = \frac{1}{1^2} - \frac{1}{2^2} + \frac{1}{2^2} - \frac{1}{3^2} + \cdots + \frac{1}{n^2} - \frac{1}{(n+1)^2} = 1 - \frac{1}{(n+1)^2} $，

因为 $ n \in \mathbb{N}^* $，所以 $ T_n = 1 - \frac{1}{(n+1)^2} < 1 $，当 $ n $增大时， $ \frac{1}{(n+1)^2} $减小，所以 $ 1 - \frac{1}{(n+1)^2} $增大，

从而 $ T_n = 1 - \frac{1}{(n+1)^2} $随着 $ n $的增大而增大，故 $ T_n \geq T_1 = 1 - \frac{1}{4} = \frac{3}{4} $，结合 $ T_n < 1 $可得 $ \frac{3}{4} \leq T_n < 1 $。

【反思】可以看到，在构造等差数列时，不一定要构造与 $ a_n $有关的结构，有时也可构造与 $ S_n $有关的等差数列来解决问题。本题就是如此

在有的情境下，可能会需要我们寻找两个数列的公共项，这类问题的处理方法大致相同，本节我们就以等差数列为例来给大家拓展如何寻找两个等差数列的公共项，若是其它数列，也可类似处理.

## 类型V：两个等差数列的公共项问题

【例 12】已知数列 $\{a_n\}$，$\{b_n\}$ 的通项公式分别为 $a_n = 4n - 3$，$b_n = 5n - 4$，由 $\{a_n\}$，$\{b_n\}$ 的公共项从小到大排列得到的数列为 $\{c_n\}$，则 $c_{100} = $（ ）

A. 1941 B. 1961 C. 1981 D. 2001

解析：通过逐个尝试寻找$\{a_n\}$和$\{b_n\}$的第100个公共项显然很麻烦，怎么办呢？可以这么来看，某个数如果是$\{a_n\}$和$\{b_n\}$的公共项，那么必定存在正整数$p$和$q$，使$a_p = b_q$，故可由此建立关于$p$，$q$的方程，再作分析，设$\{a_n\}$的第$p$项与$\{b_n\}$的第$q$项相等，即$a_p = b_q$，所以$4p - 3 = 5q - 4$，整理得：$p = \frac{5q - 1}{4}(p, q \in \mathbb{N}^*)$ ①，

 $$ q $$ 

经尝试，当 $q$ 取 1，5，9，⋯，$4n-3(n\in\mathbf{N}^*)$ 时，$p$ 为正整数，所以 $b_1$，$b_5$，$b_9$，⋯，$b_{4n-3}$，⋯，这些就是 $\{a_n\}$ 与 $\{b_n\}$ 的公共项，故第 100 个公共项为 $b_{4\times100-3}=b_{397}=5\times397-4=1981$，即 $c_{100}=1981$

答案：C

【反思】要寻找数列$\{a_n\}$和$\{b_n\}$的公共项，常令$a_p=b_q$，由此建立关于$p$，$q$的方程，并反解出$p$（也可反解出$q$，方法类似），再研究当$q$取哪些正整数时，对应的$p$也为正整数，由此找到两个数列的公共项。
