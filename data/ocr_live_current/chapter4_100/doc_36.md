【例5】已知等差数列$\{a_n\}$的前$n$项和为$S_n$，若$S_4=2S_2$，$a_2=2a_1+1$，则$S_{15}=$（）

A. $-20$ B. $-15$ C. $-10$ D. $-5$

解析：已知和所求都容易代公式，故先代公式翻译已知条件，建立方程组求出  $ a_1 $ 和  $ d $，再用它们求  $ S_{15} $

设  $ \{a_n\} $ 的公差为  $ d $，由题意， $ \begin{cases} S_4 = 2S_2 \\ a_2 = 2a_1 + 1 \end{cases} $，所以  $ \begin{cases} 4a_1 + \frac{4 \times 3}{2}d = 2\left(2a_1 + \frac{2 \times 1}{2}d\right) \\ a_1 + d = 2a_1 + 1 \end{cases} $，解得： $ \begin{cases} a_1 = -1 \\ d = 0 \end{cases} $，

所以  $ S_{15} = 15a_1 + \frac{15 \times 14}{2}d = 15 \times (-1) + \frac{15 \times 14}{2} \times 0 = -15 $。

答案：B

【反思】当涉及等差数列 $\{a_n\}$ 的前 $n$ 项和 $S_n$ 时，常考虑代公式 $S_n = \frac{n(a_1 + a_n)}{2} = na_1 + \frac{n(n-1)}{2}d$ 处理，至于具体代哪个公式，要看怎样更方便计算，我们再通过下面的变式 1 和变式 2 来巩固一下。

【变式1】（多选）已知等差数列$\{a_n\}$的前$n$项和为$S_n$，$a_1<0$，$S_7=S_{12}$，则（ ）

A. 数列$\{a_n\}$是递减数列

B. $a_{10}=0$

C. $S_n<0$时，$n$的最大值是18

D. $S_2>S_{16}$

d 与  $ a_1 $ 的关系，设数列  $ \{a_n\} $ 的公差为 d，由题意， $ S_7 = S_{12} $，所以  $ 7a_1 + \frac{7 \times 6}{2}d = 12a_1 + \frac{12 \times 11}{2}d \Rightarrow a_1 = -9d $，又因为  $ a_1 < 0 $，所以  $ d > 0 $，从而数列  $ \{a_n\} $ 为递增数列，故 A 项错误；

B 项，因为  $ a_1 = -9d $，所以  $ a_{10} = a_1 + 9d = -9d + 9d = 0 $，故 B 项正确；

C 项，已有  $ a_1 $ 和  $ d $ 的关系，可将公式  $ S_n = na_1 + \frac{n(n-1)}{2}d $ 中的  $ a_1 $ 和  $ d $ 统一起来，以便于分析其正负， $ S_n = na_1 + \frac{n(n-1)}{2}d = -9dn + \frac{d}{2}n^2 - \frac{d}{2}n = \frac{d}{2}n(n-19) $ ①，

因为  $ d > 0 $，所以  $ S_n < 0 \Leftrightarrow \frac{d}{2}n(n-19) < 0 \Leftrightarrow n(n-19) < 0 $，解得： $ 0 < n < 19 $，

结合  $ n \in \mathbb{N}^* $ 可得  $ n $ 的最大值为 18，故 C 项正确；

D 项，由①得  $ S_2 = \frac{d}{2} \times 2 \times (2-19) = -17d $， $ S_{16} = \frac{d}{2} \times 16 \times (16-19) = -24d $，结合  $ d > 0 $ 得  $ S_2 > S_{16} $，故 D 项正确。

【变式2】已知正项数列 $ \{a_{n}\} $的前n项和为 $ S_{n} $，且满足 $ a_{n}^{2}+a_{n}=2S_{n}+6 $。

（1）证明： $ \{a_{n}\} $ 为等差数列；

（2）求数列 $ \left\{\frac{S_{n}}{n}\right\} $的前n项和 $ T_{n} $.

解：（1）（条件涉及  $ a_n $ 与  $ S_n $ 的关系，要证的是与  $ a_n $ 有关的结论，考虑退  $ n $ 相减，消去  $ S_n $ 来分析）因为  $ a_n^2 + a_n = 2S_n + 6 $，所以当  $ n \geq 2 $ 时， $ a_{n-1}^2 + a_{n-1} = 2S_{n-1} + 6 $，

两式作差得  $ a_n^2 + a_n - a_{n-1}^2 - a_{n-1} = 2(S_n - S_{n-1}) = 2a_n $，整理得： $ (a_n + a_{n-1})(a_n - a_{n-1} - 1) = 0 $，

又因为  $ \{a_n\} $ 为正项数列，所以  $ a_n + a_{n-1} > 0 $，从而  $ a_n - a_{n-1} - 1 = 0 $，故  $ a_n - a_{n-1} = 1 $，

在  $ a_n^2 + a_n = 2S_n + 6 $ 中令  $ n = 1 $ 得  $ a_1^2 + a_1 = 2S_1 + 6 = 2a_1 + 6 $，解得： $ a_1 = 3 $ 或  $ -2 $（舍去），

所以  $ \{a_n\} $ 是首项为 3，公差  $ d = 1 $ 的等差数列。
