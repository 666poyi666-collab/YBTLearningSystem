所以当 $ n \geq 18 $时，必有 $ S_n < S_{17} < 0 $，从而使 $ S_n > 0 $成立的最大自然数n是16，故D项错误。

答案：ABC

【变式2】已知在等差数列 $ \{a_n\} $中， $ a_1<0 $， $ S_9=S_{12} $，则当 $ S_n $最小时， $ n= $___。

解法 1：要研究何时 $S_n$ 最小，只需找到 $\{a_n\}$ 为负数的最后一项，可先用公式翻译 $S_9 = S_{12}$，找到 $a_1$ 和 $d$ 的关系，由题意，$S_9 = S_{12}$，所以 $9a_1 + \frac{9 \times 8}{2}d = 12a_1 + \frac{12 \times 11}{2}d$，化简得：$a_1 + 10d = 0$，所以 $a_1 = -10d$，故 $a_n = a_1 + (n-1)d = -10d + (n-1)d = (n-1)d$，又因为 $a_1 < 0$，所以 $d > 0$，故当 $n \leq 10$ 时，$a_n < 0$；$a_{11} = 0$；当 $n \geq 12$ 时，$a_n > 0$；所以当 $S_n$ 最小时，$n = 10$ 或 11。

解法2：研究何时 $ S_n $最小的核心是研究 $ \{a_n\} $的项的特征，故也可考虑将 $ S_9 = S_{12} $转化成项来分析，如何转化？直接作差即可，因为 $ S_9 = S_{12} $，所以 $ S_{12} - S_9 = a_{10} + a_{11} + a_{12} = 3a_{11} = 0 \Rightarrow a_{11} = 0 $，又因为 $ a_1 < 0 $，所以数列 $ \{a_n\} $的前10项为负数，第11项为0，从第12项起全部为正数，故当 $ S_n $最小时， $ n = 10 $或11.

答案：10 或 11

## 类型IV：等差数列前 n 项和的实际应用

【例 11】2024 年两会报告中提出 “大力推进现代化产业体系建设，加快发展新质生产力”，所谓新质生产力，是创新主导、以科技创新作为核心要素的先进生产力质态。今年全国两会，“新质生产力”已成为 C 位热词。某创新公司落实两会精神，准备年初用 980 万元购买新设备用来创新，第一年使用的各种创新费用 120 万元，以后每年还要持续增加创新费用 40 万元，公司每年经过创新后的收益为 500 万元。

（1）创新公司第几年开始获利？

（2）经过多少年创新公司获得的年平均利润最大？最大年平均利润是多少？

解：（1）（利润=总收益-总成本，这里需要注意成本分成两个部分，一个是买设备的固定成本，另一个则是创新费用，不难发现每年的创新费用成等差数列，所以到第 $n$ 年的总费用可代等差数列的前 $n$ 项和公式计算）

由题意，设公司到第 $n$ 年的累计利润为 $f(n)$，由题意，$f(n)=500n-\left[120n+\frac{n(n-1)}{2}\times40\right]-980$，

整理得： $ f(n)=-20n^{2}+400n-980 $，要使公司获利，则 $ f(n)=-20n^{2}+400n-980>0 $，

解得： $ 10 - \sqrt{51} < n < 10 + \sqrt{51} $，又因为 $ n \in \mathbb{N}^* $， $ 7 < \sqrt{51} < 8 $，所以 $ 3 \leq n \leq 17 $，故公司第3年开始获利。

（2）由题意，该公司的年平均利润为 $ \frac{f(n)}{n}=\frac{-20n^{2}+400n-980}{n}=-20\left(n+\frac{49}{n}\right)+400 $ ①，

因为 $ n \in \mathbb{N}^* $，所以 $ n + \frac{49}{n} \geq 2\sqrt{n \cdot \frac{49}{n}} = 14 $，当且仅当 $ n = 7 $时等号成立，

代入①得 $ \frac{f(n)}{n}=-20\left(n+\frac{49}{n}\right)+400\leq-20\times14+400=120 $

所以公司经过7年可获得的年平均利润最大，最大年平均利润为120万元.

【反思】等差数列的前 n 项和公式在实际问题中有广泛的应用，解决这类问题的基本步骤是：①阅读材料，将其转化为等差数列模型，并设出有关变量，从而将实际问题转化为等差数列问题；②分析已知条件，求解数列问题；③回归实际，将求得的结果翻译成实际问题中的结果.
