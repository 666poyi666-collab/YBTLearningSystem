## 知识点 1：等差数列的前 n 项和公式及其推导

1. 等差数列的前 $n$ 项和公式

首项为 $a_1$，末项为 $a_n$，项数为 $n$ 的等差数列 $\{a_n\}$ 的前 $n$ 项和为 $S_n = \frac{n(a_1 + a_n)}{2}$。

设 $\{a_n\}$ 的公差为 $d$，将 $a_n = a_1 + (n-1)d$ 代入上式整理可得 $S_n = na_1 + \frac{n(n-1)}{2}d$。

注：两个求和公式涉及的量不同，因此需要根据实际情况选择适当的公式解题，不难发现，通常已知 $ a_{1} $， $ a_{n} $， $ S_{n} $，n，d这五个量中的三个量，就能求出另外两个量.

2. 等差数列的前 $n$ 项和公式 $S_n = \frac{n(a_1 + a_n)}{2}$ 的推导

设 $S_n = a_1 + a_2 + \cdots + a_{n-1} + a_n$ ①，

则 $S_n = a_n + a_{n-1} + \cdots + a_2 + a_1$ ②，

① + ② 可得 $2S_n = (a_1 + a_n) + (a_2 + a_{n-1}) + \cdots + (a_{n-1} + a_2)$

$+(a_n + a_1)$，

由等差数列的性质，$a_1 + a_n = a_2 + a_{n-1} = \cdots = a_n + a_1$，

所以 $2S_n = n(a_1 + a_n)$，故 $S_n = \frac{n(a_1 + a_n)}{2}$。

【例1】（1）已知等差数列$\{a_n\}$中，$a_n=2n-1$，则其前$n$项和$S_n=$___；

（2）已知等差数列$\{a_n\}$前$n$项和为$S_n$，$a_9=9$，则$S_{17}=$___；

（3）已知等差数列$\{a_n\}$中，$a_1=1$，

公差$d=2$，则这个数列的前10项和为___。

解析：（1）由题意，$a_1=2\times1-1=1$，

所以$S_n=\frac{n(a_1+a_n)}{2}=\frac{n(1+2n-1)}{2}=n^2$。

（2）由题意，$S_{17}=\frac{(a_1+a_{17})}{2}\times17$

$=\frac{2a_9}{2}\times17=17a_9=17\times9=153$。

（3）由题意，$S_{10}=10a_1+\frac{10\times9}{2}d$

$=10\times1+\frac{10\times9}{2}\times2=100$。

答案：（1） $ n^{2} $；（2）153；（3）100

【例2】在等差数列$\{a_n\}$中，$a_1>0$，$d=\frac{1}{2}$，$a_n=3$，$S_n=\frac{15}{2}$，则$a_1=$___；$n=$___。

解析：由题意，$\begin{cases}a_n=a_1+(n-1)d\\S_n=\dfrac{n(a_1+a_n)}{2}\end{cases}$，

所以$\begin{cases}3=a_1+(n-1)\cdot\dfrac{1}{2}\\\dfrac{15}{2}=\dfrac{n(a_1+3)}{2}\end{cases}$，

解得：$\begin{cases}a_1=-\dfrac{3}{2}\\n=10\end{cases}$或$\begin{cases}a_1=2\\n=3\end{cases}$，

又因为$a_1>0$，所以$a_1=2$，$n=3$。

答案：2；3
