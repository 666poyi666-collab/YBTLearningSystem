出数列$\left\{\frac{1}{b_n b_{n+1}}\right\}$的前$n$项和，这是最基础的裂项相消法，本题第（2）问即为$b_n=n$的情况。裂项相消还有其它更复杂的情形，我们来看下面的两个变式。

【变式1】已知正项数列 $ \{a_{n}\} $的前n项之积为 $ T_{n} $，且 $ \frac{1}{a_{n}}=1-\frac{3}{T_{n}} $.

（1）求证：数列 $ \{T_{n}\} $是等差数列；

（2）设 $ b_{n}=(-1)^{n}\cdot\frac{6n+5}{T_{n}T_{n+1}} $，求数列 $ \{b_{n}\} $的前2n项和 $ S_{2n} $.

解：（1）（条件给出 $a_n$ 与 $T_n$ 混搭的关系式，要证的是 $\{T_n\}$ 为等差数列，故考虑将 $a_n = \frac{T_n}{T_{n-1}} (n \geq 2)$ 代入，消去 $a_n$）因为 $\frac{1}{a_n} = 1 - \frac{3}{T_n}$，又当 $n \geq 2$ 时，$a_n = \frac{T_n}{T_{n-1}}$，所以 $\frac{T_{n-1}}{T_n} = 1 - \frac{3}{T_n}$，从而 $T_{n-1} = T_n - 3$，故 $T_n - T_{n-1} = 3$ ①，在 $\frac{1}{a_n} = 1 - \frac{3}{T_n}$ 中令 $n = 1$ 得 $\frac{1}{a_1} = 1 - \frac{3}{T_1} = 1 - \frac{3}{a_1}$，解得：$a_1 = 4$，所以 $T_1 = 4$，结合①可得 $\{T\}$ 是首项为 4，公差为 3 的等差数列

（2）由（1）可得  $ T_{n}=4+(n-1)\cdot3=3n+1 $ ，所以  $ b_{n}=(-1)^{n}\cdot\frac{6n+5}{(3n+1)(3n+4)} $

(2) 由 (1) 可得  $ t_n = 4 + (n-1) \cdot 3 = 3n + 1 $，所以  $ b_n = (-1) \cdot \frac{(3n+1)(3n+4)}{(3n+1)(3n+4)} $，

(怎样求  $ \{b_n\} $ 的前 2n 项和？可以想象，若是  $ \frac{1}{(3n+1)(3n+4)} $，则可裂项为  $ \frac{1}{3}\left(\frac{1}{3n+1} - \frac{1}{3n+4}\right) $，但这里  $ b_n $ 的分子不是 1，前面也乘以了  $ (-1)^n $，怎么办呢？可以想象， $ \frac{1}{3n+1} + \frac{1}{3n+4} = \frac{6n+5}{(3n+1)(3n+4)} $，故可尝试用它来裂项）

因为  $ b_n = (-1)^n \cdot \frac{6n+5}{(3n+1)(3n+4)} = (-1)^n \left(\frac{1}{3n+1} + \frac{1}{3n+4}\right) $，所以  $ S_{2n} = b_1 + b_2 + b_3 + b_4 + \cdots + b_{2n-1} + b_{2n} = -\frac{1}{4} - \frac{1}{7} + \frac{1}{7} + \frac{1}{10} - \frac{1}{10} - \frac{1}{13} + \frac{1}{13} + \frac{1}{16} - \cdots - \frac{1}{6n-2} - \frac{1}{6n+1} + \frac{1}{6n+1} + \frac{1}{6n+4} = -\frac{1}{4} + \frac{1}{6n+4} = -\frac{3n}{4(3n+2)} $。

【反思】可以看到，除了像例1那种最常规的裂项相消之外，还有其它更复杂的裂项，本题就是一个例子。裂项相消的本质是把通项进行适当的拆分，产生前后项关系，进而求和时能抵消一部分，所以裂项的关键是观察出数列通项的局部所具有的前后项关系（例如本题的 $ 3n+1 $和 $ 3n+4 $），下面我们再举一个例子。

【变式2】记 $ S_{n} $为数列 $ \{a_{n}\} $的前n项和，已知 $ 3S_{n}=4a_{n}-3n $

（1）求 $ a_{n} $；（2）设 $ b_{n}=\frac{a_{n}+1}{a_{n}a_{n+1}} $，求数列 $ \{b_{n}\} $的前n项和 $ T_{n} $.

解：（1）（条件给出  $ a_n $ 与  $ S_n $ 混搭的关系式，让求  $ a_n $，可考虑退  $ n $ 相减，消去  $ S_n $）

因为  $ 3S_n = 4a_n - 3n $，所以当  $ n \geq 2 $ 时， $ 3S_{n-1} = 4a_{n-1} - 3(n-1) $，

两式相减得  $ 3S_n - 3S_{n-1} = 3a_n = 4a_n - 3n - 4a_{n-1} + 3(n-1) $，化简得： $ a_n = 4a_{n-1} + 3 $ ①，

（看到形如  $ a_n = Aa_{n-1} + B(A \neq 0, A \neq 1, B \neq 0) $ 的结构，想到用待定系数法构造等比数列，可设  $ a_n + \lambda = 4(a_{n-1} + \lambda) $，则  $ a_n = 4a_{n-1} + 3\lambda $，与  $ a_n = 4a_{n-1} + 3 $ 对比可得  $ \lambda = 1 $，构造的方法就有了）

由①可得  $ a_n + 1 = 4(a_{n-1} + 1) $，在  $ 3S_n = 4a_n - 3n $ 中令  $ n = 1 $ 得  $ 3S_1 = 4a_1 - 3 $，结合  $ S_1 = a_1 $ 可得  $ a_1 = 3 $，

所以  $ a_1 + 1 = 4 $，又  $ a_n + 1 = 4(a_{n-1} + 1) $，所以  $ \{a_n + 1\} $ 是首项和公比都为 4 的等比数列，

从而  $ a_n + 1 = 4 \times 4^{n-1} = 4^n $，故  $ a_n = 4^n - 1 $。
