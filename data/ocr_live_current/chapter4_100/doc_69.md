答案：ACD

【反思】等比数列 $\{a_n\}$ 的单调性由首项 $a_1$ 和公比 $q$ 共同决定. 具体来说, 当 $\begin{cases} a_1 > 0 \\ q > 1 \end{cases}$ 或 $\begin{cases} a_1 < 0 \\ 0 < q < 1 \end{cases}$ 时, $\{a_n\}$ 为递增数列; 当 $\begin{cases} a_1 > 0 \\ 0 < q < 1 \end{cases}$ 或 $\begin{cases} a_1 < 0 \\ q > 1 \end{cases}$ 时, $\{a_n\}$ 为递减数列; 当 $q < 0$ 时, $\{a_n\}$ 为摆动数列, 不单调; 当 $q = 1$ 时, $\{a_n\}$ 为常数数列.

## 补充、拓展

等差数列和等比数列经常综合出题，为此我们设计了下面的类型V来进行拓展；另外，有时我们也会遇到与等比数列有关的新定义问题，这类问题没有固定的套路，只能见招拆招，后面的类型VI中我们会举例.

## 类型V：等差、等比数列综合题

【例 7】已知数列 $\{a_n\}$ 的前 $n$ 项和是 $S_n$，且 $S_n = 2a_n - 2(n \in \mathbb{N}^*)$，等差数列 $\{b_n\}$ 满足 $b_1 = 1$，且 $b_2$，$b_3 + 1$，$b_6 + 1$ 成等比数列。

（1）求数列 $ \{a_{n}\} $与 $ \{b_{n}\} $的通项公式；

（2）求数列 $ \left\{\frac{b_{n}}{a_{n}}\right\} $的最大项.

解：（1）（先看  $ a_n $，条件给出了  $ S_n $ 与  $ a_n $ 混搭的关系式，要求  $ a_n $，故考虑退 n 相减，消去  $ S_n $）

由题意， $ S_n = 2a_n - 2 $，所以当  $ n \geq 2 $ 时， $ S_{n-1} = 2a_{n-1} - 2 $，两式相减得  $ S_n - S_{n-1} = 2a_n - 2a_{n-1} $，

所以  $ a_n = 2a_n - 2a_{n-1} $，故  $ a_n = 2a_{n-1} $，在  $ S_n = 2a_n - 2 $ 中令  $ n = 1 $ 可得  $ S_1 = 2a_1 - 2 $，结合  $ S_1 = a_1 $ 可得  $ a_1 = 2 $，

所以  $ \{a_n\} $ 是首项为 2，公比为 2 的等比数列，故  $ a_n = 2 \times 2^{n-1} = 2^n $，

（再看 $ b_{n} $，已有首项，求 $ b_{n} $只差公差，故直接代公式翻译已知条件，建立方程求公差）

设等差数列 $\{b_n\}$ 的公差为 $d$，则 $b_2 = b_1 + d = d + 1$，$b_3 + 1 = b_1 + 2d + 1 = 2d + 2$，$b_6 + 1 = b_1 + 5d + 1 = 5d + 2$，由题意，$(b_3 + 1)^2 = b_2(b_6 + 1)$，所以 $(2d + 2)^2 = (d + 1)(5d + 2)$，整理得：$d^2 - d - 2 = 0$，解得：$d = -1$ 或 2，（两个解都可取吗？$(b_3 + 1)^2 = b_2(b_6 + 1)$ 不一定能保证 $b_2$，$b_3 + 1$，$b_6 + 1$ 均不为 0，故还需检验）当 $d = -1$ 时，$b_2 = b_1 - 1 = 0$，不合题意，当 $d = 2$ 时，$b_2$，$b_3 + 1$，$b_6 + 1$ 均不为 0，所以 $\{b_n\}$ 是首项为 1，公差为 2 的等差数列，故 $b_1 = 1 + (n - 1) \times 2 = 2n - 1$。

（2）解法1：由（1）可得 $ \frac{b_n}{a_n} = \frac{2n-1}{2^n} $，（怎样求 $ \frac{2n-1}{2^n} $的最大值？可将其看成数列的通项公式，通过作差比较分析其单调性，用单调性来研究最大值）

令 $ c_n = \frac{2n-1}{2^n} $，则 $ c_{n+1} - c_n = \frac{2(n+1)-1}{2^{n+1}} - \frac{2n-1}{2^n} = \frac{2n+1}{2^{n+1}} - \frac{2(2n-1)}{2^{n+1}} = \frac{3-2n}{2^{n+1}} $，

当 $ n=1 $时， $ c_{n+1} - c_n > 0 $，所以 $ c_{n+1} > c_n $；当 $ n \geq 2 $时， $ c_{n+1} - c_n < 0 $，所以 $ c_{n+1} < c_n $；故 $ c_1 < c_2 > c_3 > c_4 > \cdots $，

所以当 $ n=2 $时， $ c_n $取得最大值，且最大值为 $ c_2 = \frac{2 \times 2 - 1}{2^2} = \frac{3}{4} $，故数列 $ \left\{\frac{b_n}{a_n}\right\} $的最大项为 $ \frac{3}{4} $。

解法2：（按解法1得到 $ c_{n}=\frac{2n-1}{2^{n}} $后，要研究 $ c_{n} $的最大值，也可以这样想，假设 $ c_{k} $最大，那么 $ c_{k} $必定不小于它的前一项和后一项，由此可建立不等式组，求出k）
