（2）由（1）可得  $ b_n = \frac{a_n + 1}{a_n a_{n+1}} = \frac{4^n}{(4^n - 1)(4^{n+1} - 1)} $，（怎样求  $ T_n $？观察发现  $ b_n $ 分母上的  $ 4^n - 1 $ 与  $ 4^{n+1} - 1 $ 属前后项关系，故可考虑用裂项相消法求  $ T_n $，可先拆分成  $ \frac{1}{4^n - 1} - \frac{1}{4^{n+1} - 1} $，通分化简得  $ \frac{1}{4^n - 1} - \frac{1}{4^{n+1} - 1} = \frac{3 \times 4^n}{(4^n - 1)(4^{n+1} - 1)} $，与  $ b_n $ 的通项公式对比可知多了个系数 3，于是乘以  $ \frac{1}{3} $ 即可调整为  $ b_n $，裂项就完成了）

所以  $ b_n = \frac{1}{3} \left( \frac{1}{4^n - 1} - \frac{1}{4^{n+1} - 1} \right) $，故  $ T_n = b_1 + b_2 + \cdots + b_n = \frac{1}{3} \left( \frac{1}{4^1 - 1} - \frac{1}{4^2 - 1} + \frac{1}{4^2 - 1} - \frac{1}{4^3 - 1} + \cdots + \frac{1}{4^n - 1} - \frac{1}{4^{n+1} - 1} \right) = \frac{1}{3} \left( \frac{1}{4^1 - 1} - \frac{1}{4^{n+1} - 1} \right) = \frac{1}{3} \left( \frac{1}{3} - \frac{1}{4^{n+1} - 1} \right) $。

## 类型Ⅱ：错位相减法求前 n 项和

【例2】已知数列 $ \{a_{n}\} $的前n项和为 $ S_{n} $，且 $ 2S_{n}+9=3a_{n}+4n $

（1）求数列 $ \{a_{n}\} $的通项公式；

（2）求数列 $ \{n(a_{n}-2)\} $的前n项和 $ T_{n} $

解：（1）（条件给出  $ a_n $ 与  $ S_n $ 混搭的关系式，要求  $ a_n $，可考虑退  $ n $ 相减，消去  $ S_n $）

因为  $ 2S_n + 9 = 3a_n + 4n $，所以当  $ n \geq 2 $ 时， $ 2S_{n-1} + 9 = 3a_{n-1} + 4(n-1) $，

两式作差得  $ 2S_n + 9 - (2S_{n-1} + 9) = 3a_n + 4n - [3a_{n-1} + 4(n-1)] $，所以  $ 2a_n = 3a_n - 3a_{n-1} + 4 $，故  $ a_n = 3a_{n-1} - 4 $ ①，

（看到  $ a_n = Aa_{n-1} + B $ 这种结构的递推公式，想到用待定系数法构造等比数列。可设  $ a_n + \lambda = 3(a_{n-1} + \lambda) $，则  $ a_n = 3a_{n-1} + 2\lambda $，与  $ a_n = 3a_{n-1} - 4 $ 对比可知  $ 2\lambda = -4 $，所以  $ \lambda = -2 $，构造的方法就有了）

由①可得  $ a_n - 2 = 3(a_{n-1} - 2) $，在  $ 2S_n + 9 = 3a_n + 4n $ 中取  $ n = 1 $ 可得  $ 2S_1 + 9 = 3a_1 + 4 $，结合  $ S_1 = a_1 $ 可得  $ a_1 = 5 $，

所以  $ a_1 - 2 = 5 - 2 = 3 $，从而  $ \{a_n - 2\} $ 是首项为 3，公比为 3 的等比数列，故  $ a_n - 2 = 3 \times 3^{n-1} = 3^n $，所以  $ a_n = 3^n + 2 $

（2）由（1）得  $ a_n - 2 = 3^n $，所以  $ n(a_n - 2) = n \cdot 3^n $，（涉及“等差×等比”结构，可用错位相减法求前  $ n $ 项和）所以  $ \begin{cases} T_n = 1 \times 3 + 2 \times 3^2 + 3 \times 3^3 + \cdots + (n-1) \cdot 3^{n-1} + n \times 3^n \end{cases} $ ②， $ 3T_n = 1 \times 3^2 + 2 \times 3^3 + 3 \times 3^4 + \cdots + (n-1) \times 3^n + n \times 3^{n+1} $ ③，②-③得  $ -2T_n = 3 + 3^2 + 3^3 + \cdots + 3^n - n \times 3^{n+1} = \frac{3(1-3^n)}{1-3} - n \times 3^{n+1} = \frac{3(3^n - 1)}{2} - n \times 3^{n+1} = \frac{3^{n+1} - 3 - 2n \times 3^{n+1}}{2} = \frac{(1-2n) \times 3^{n+1} - 3}{2} $，所以  $ T_n = \frac{(2n-1)3^{n+1} + 3}{4} $。

【反思】“等差×等比”这类数列可用错位相减法求和，此法往往计算量大，容易算错，可代 n=1 来检验计算结果是否正确。例如本题第（2）问，算得的  $ T_{n} $ 必须满足  $ T_{1}=a_{1}-2 $，经检验， $ T_{1}=3=a_{1}-2 $，是满足的，检验的过程在草稿纸上完成即可，不作为正式作答的步骤。
