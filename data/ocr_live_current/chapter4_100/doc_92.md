（2）若将数列 $\{b_n\}$ 中去掉数列 $\{a_n\}$ 的项后余下的项按原顺序组成数列 $\{c_n\}$，求 $c_1 + c_2 + \cdots + c_{30}$ 的值。

解：（1）因为 $n$，$a_n$，$S_n$ 成等差数列，所以 $S_n + n = 2a_n$ ①，（这是 $a_n$ 与 $S_n$ 混搭的关系式，所求为 $a_n$，故考虑退 $n$ 相减，消去 $S_n$）故当 $n \geq 2$ 时，$S_{n-1} + n - 1 = 2a_{n-1}$，两式相减得：$S_n + n - [S_{n-1} + (n-1)] = 2a_n - 2a_{n-1}$，

又 $S_n + n - [S_{n-1} + (n-1)] = S_n - S_{n-1} + n - n + 1 = a_n + 1$，所以 $a_n + 1 = 2a_n - 2a_{n-1}$，故 $a_n = 2a_{n-1} + 1$ ②，

（看到形如 $a_n = Aa_{n-1} + B(A \neq 0, A \neq 1, B \neq 0)$ 的结构，想到用待定系数法构造等比数列，可设 $a_n + \lambda = 2(a_{n-1} + \lambda)$，则 $a_n = 2a_{n-1} + \lambda$，与 $a_n = 2a_{n-1} + 1$ 对比可得 $\lambda = 1$，构造的方法就有了）

由②可得 $a_n + 1 = 2(a_{n-1} + 1)$，在①中取 $n = 1$ 得 $S_1 + 1 = 2a_1$，结合 $S_1 = a_1$ 可得 $a_1 = 1$，所以 $a_1 + 1 = 2$，

从而 $\{a_n + 1\}$ 是首项和公比均为 2 的等比数列，故 $a_n + 1 = 2 \times 2^{n-1} = 2^n$，所以 $a_n = 2^n - 1$。

（2）（条件给出  $ b_{n+1}=2b_n-2n+3 $，考虑用构造法求  $ b_n $，如何构造？该式中除  $ b_{n+1} $ 和  $ b_n $ 外，还有一次函数结构  $ -2n+3 $，该结构的前后项可统一表述为  $ An+B $ 与  $ A(n+1)+B $，于是可设  $ b_{n+1}+A(n+1)+B=2(b_n+An+B) $，整理得  $ b_{n+1}=2b_n+An-A+B $，与所给递推公式对比得  $ \begin{cases}A=-2\\-A+B=3\end{cases} $，于是  $ \begin{cases}A=-2\\B=1\end{cases} $，构造的方法就有了）

因为 $ b_{n+1}=2b_n-2n+3 $，所以 $ b_{n+1}-2(n+1)+1=2(b_n-2n+1) $③，
