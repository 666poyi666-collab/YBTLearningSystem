【反思】公比  $ q \neq 1 $ 的等比数列的通项公式与前 n 项和公式都涉及  $ q^{n} $ 这一结构，它们的函数类型是一样的，所以往往存在着类似于本题的  $ S_{n} = 1 - a_{n} $ 这样的关系式，所以看到这类关系式时，可以预判  $ \{a_{n}\} $ 为等比数列，接下来的解题就更具有方向性。那如果把  $ S_{n} = 1 - a_{n} $ 中的 1 换成与 n 有关的结构又怎样处理呢？我们来看下面的变式。

【变式】已知数列 $ \{a_{n}\} $的前n项和是 $ S_{n} $，且 $ S_{n}=2a_{n}-n $，求：

（1）数列 $ \{a_{n}\} $的通项公式：

（2）数列 $ \{a_{n}\} $落入区间(1,2024)内的所有项的和.

解：（1）（条件给出  $ S_n $ 与  $ a_n $ 混搭的关系式，要求  $ a_n $，考虑退  $ n $ 相减，消去  $ S_n $）

由题意， $ S_n = 2a_n - n $，所以当  $ n \geq 2 $ 时， $ S_{n-1} = 2a_{n-1} - (n-1) $，两式相减得  $ S_n - S_{n-1} = 2(a_n - a_{n-1}) - n + (n-1) $，

所以  $ a_n = 2a_n - 2a_{n-1} - 1 $，故  $ a_n = 2a_{n-1} + 1 $ ①，（此递推式为形如  $ a_n = Aa_{n-1} + B $ 的形式，可用待定系数法构造等比数列求  $ a_n $，设  $ a_n + \lambda = 2(a_{n-1} + \lambda) $，则  $ a_n = 2a_{n-1} + \lambda $，与  $ a_n = 2a_{n-1} + 1 $ 对比可得  $ \lambda = 1 $，构造的方法就有了）

由①可得  $ a_n + 1 = 2a_{n-1} + 2 = 2(a_{n-1} + 1) $，在  $ S_n = 2a_n - n $ 中令  $ n = 1 $ 得  $ S_1 = 2a_1 - 1 $，结合  $ S_1 = a_1 $ 可得  $ a_1 = 1 $，

所以  $ a_1 + 1 = 2 $，从而  $ \{a_n + 1\} $ 是首项为 2，公比为 2 的等比数列，故  $ a_n + 1 = 2^n $，所以  $ a_n = 2^n - 1 $。

令$1<a_n<2024$可得$1<2^n-1<2024$，所以$2<2^n<2025$，因为$2^{10}=1024<2025$，$2^{11}=2048>2025$，

所以满足$2<2^n<2025$的$n$为2，3，4，⋯，10，故所求的和为$a_2+a_3+a_4+\cdots+a_{10}=2^2-1+2^3-1+\cdots+2^{10}-1=2^2+2^3+\cdots+2^{10}-9=\frac{2^2\times(1-2^9)}{1-2}-9=2^{11}-2^2-9=2035$。

## 类型IV：等比数列的单调性分析

【例6】（多选）若等比数列$\{a_n\}$的公比为$q$，前$n$项和为$S_n$，前$n$项积为$T_n$，且$\forall n\in\mathbb{N}^*$，$\frac{a_1q^n}{1-q}<0$，则（ ）

A. 数列$\{a_n\}$是递增数列

B. 数列$\{a_n\}$是递减数列

C. 若数列$\{S_n\}$是递增数列，则$q>1$

D. 若数列$\{T_n\}$是递增数列，则$q>1$

解析：A 项，$\{a_n\}$ 的单调性由 $a_1$ 和 $q$ 共同决定，故尝试由 $\frac{a_1 q^n}{1-q} < 0$ 分析 $a_1$ 和 $q$ 的情况，该不等式中 $q^n$ 随 $n$ 的变化而改变，其余部分是常数，故可以想象，当 $n$ 变化时，$q^n$ 正负一定不变，否则 $\frac{a_1 q^n}{1-q} < 0$ 不可能恒成立，于是从这里出发分析，因为 $\frac{a_1 q^n}{1-q} < 0$ 对任意的 $n \in \mathbb{N}^*$ 恒成立，所以 $q^n$ 不变号，故 $q > 0$ （若 $q < 0$，则 $q^n$ 正负交替，$\frac{a_1 q^n}{1-q} < 0$ 不可能恒成立），所以 $q^n > 0$，从而 $\frac{a_1 q^n}{1-q} < 0 \Leftrightarrow \frac{a_1}{1-q} < 0$，故 $a_1 > 0$，$q > 1$ 或 $a_1 < 0$，$0 < q < 1$，有两种可能的情况，下面分别考虑，怎样由此判断 $\{a_n\}$ 的单调性？可用 $a_{n+1}$ 与 $a_n$ 作差比较，当 $a_1 > 0$，$q > 1$ 时，$\{a_n\}$ 是正项数列，所以 $a_{n+1} - a_n = a_n q - a_n = a_n (q - 1) > 0 \Leftrightarrow a_{n+1} > a_n$，故 $\{a_n\}$ 是递增数列；

有两种可能的情况，下面分别考虑，怎样由此判断 $ \{a_n\} $的单调性？可用 $ a_{n+1} $与 $ a_n $作差比较，

当 $ a_1>0 $， $ q>1 $时， $ \{a_n\} $是正项数列，所以 $ a_{n+1}-a_n=a_n q-a_n=a_n(q-1)>0\Rightarrow a_{n+1}>a_n $，故 $ \{a_n\} $是递增数列；

当 $ a_1<0 $， $ 0<q<1 $时， $ \{a_n\} $是负项数列，所以 $ a_{n+1}-a_n=a_n q-a_n=a_n(q-1)>0 $，从而 $ a_{n+1}>a_n $，

故 $ \{a_n\} $也是递增数列；故A项正确，B项错误；

C 项，若数列 $\{S_n\}$ 是递增数列，则 $S_{n+1} - S_n = a_{n+1} > 0$，由前面的分析可知只能 $a_1 > 0$，$q > 1$，故 C 项正确；

D 项，由前面的分析可知当 $a_1 < 0$，$0 < q < 1$ 时，$a_n < 0$，又 $T_n = a_1 a_2 a_3 \cdots a_n$，所以数列 $\{T_n\}$ 中的项一定会正负交替，从而 $\{T_n\}$ 不可能是递增数列，故只能 $a_1 > 0$，$q > 1$，故 D 项正确。
