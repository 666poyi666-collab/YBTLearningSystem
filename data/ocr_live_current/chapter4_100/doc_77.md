### 4.4 $ ^{*} $ 数学归纳法

习题：P1

## 知识梳理

### 1. 数学归纳法

在证明与自然数 n 有关的命题时，可以按下面两个步骤进行：

①归纳奠基：证明当 n 取初始值  $ n_{0} $ 时，命题成立；

②归纳递推：假设当  $ n = k (k \geq n_0, k \in \mathbb{N}) $ 时命题成立，并由此出发去证明当  $ n = k + 1 $ 时，命题也成立。

完成了上述的步骤①②，就能得出命题对任意的 $ n \geq n_0 $都成立，这种证明与正整数 $ n $有关的命题的方法叫做数学归纳法。

### 2. 数学归纳法的原理解读

上述步骤②说明在  $ n = k (k \geq n_0, k \in \mathbb{N}) $ 时命题成立，可以推出当  $ n = k + 1 $ 时命题也成立。而我们在①中已经证明了当  $ n = n_0 $ 时命题成立，故结合②就能得出当  $ n = n_0 + 1 $ 时，命题成立；由  $ n = n_0 + 1 $ 时命题成立结合②又能得出当  $ n = n_0 + 2 $ 时命题也成立；如此递推下去，可发现对任意的  $ n \geq n_0 $，命题都成立，这就是数学归纳法的原理。由此原理可以看出，步骤①不可或缺，它是后续递推的起点，没有这一步，后面的逐级递推可能都是无效的。

类型 I：用数学归纳法证明等式

【例 1】用数学归纳法证明： $ 1^3 + 2^3 + 3^3 + \cdots + n^3 = \left[\frac{n(n+1)}{2}\right]^2 $。

证明：（用数学归纳法证明与正整数n有关的结论，先验证当n取初始值时结论成立，这里n的初始值为1）

(i)当 $ n=1 $时，左边 $ =1^3=1 $，右边 $ \left[\frac{1\times(1+1)}{2}\right]^2=1 $，所以结论成立；

（接下来需假设当  $ n = k (k \geq 1) $ 时结论成立，并由此出发去推导当  $ n = k + 1 $ 时，结论也成立）

(ii)假设当 $ n=k(k\geq1) $时，结论成立，即 $ 1^3+2^3+3^3+\cdots+k^3=\left[\frac{k(k+1)}{2}\right]^2 $①，

（接下来需要证明当 $n=k+1$ 时结论也成立，也就是证明在题干所给等式中将 $n$ 换成 $k+1$ 所得的结果成立，即 $1^3 + 2^3 + 3^3 + \cdots + k^3 + (k+1)^3 = \left[\frac{(k+1)(k+2)}{2}\right]^2$，怎么证？只需运用归纳假设，将式①代入，化简整理即可）

 $$ 1^{3}+2^{3}+3^{3}+\cdots+k^{3}+(k+1)^{3}=\left[\frac{k(k+1)}{2}\right]^{2}+(k+1)^{3}=(k+1)^{2}\left(\frac{k^{2}}{4}+k+1\right)=(k+1)^{2}\cdot\frac{k^{2}+4k+4}{4} $$
