因为两个焦点分别为  $ F_1(-1,0) $， $ F_2(1,0) $，所以可设椭圆的方程为  $ \frac{x^2}{a^2} + \frac{y^2}{b^2} = 1 (a > b > 0) $，且椭圆的半焦距  $ c = 1 $，又  $ \left|MF_1\right| + \left|MF_2\right| = 2a = 2\sqrt{5} $，所以  $ a = \sqrt{5} $，从而  $ b^2 = a^2 - c^2 = (\sqrt{5})^2 - 1^2 = 4 $，故椭圆的标准方程为  $ \frac{x^2}{5} + \frac{y^2}{4} = 1 $。

（2）因为两个焦点分别为  $ (- \sqrt{2}, 0) $， $ (\sqrt{2}, 0) $，所以可设椭圆的方程为  $ \frac{x^2}{a^2} + \frac{y^2}{b^2} = 1 (a > b > 0) $，且椭圆的半焦距  $ c = \sqrt{2} $，所以  $ a^2 - b^2 = 2 $ ①，

（还差一个方程就能求出 $a$ 和 $b$，条件给出了椭圆上一点的坐标，代入椭圆方程就能得到一个方程）

因为椭圆经过点 $\left(2, \frac{2\sqrt{3}}{3}\right)$，所以 $\frac{2^2}{a^2} + \frac{\left(\frac{2\sqrt{3}}{3}\right)^2}{b^2} = 1$，整理得：$\frac{4}{a^2} + \frac{4}{3b^2} = 1$ ②，

由①得 $a^2 = b^2 + 2$，代入②得 $\frac{4}{b^2 + 2} + \frac{4}{3b^2} = 1$，化简得：$3b^4 - 10b^2 - 8 = 0$，解得：$b^2 = 4$ 或 $-\frac{2}{3}$（舍去），

所以 $a^2 = b^2 + 2 = 4 + 2 = 6$，故该椭圆的标准方程为 $\frac{x^2}{6} + \frac{y^2}{4} = 1$。

（3）（由所给椭圆上的两点无法直接判断焦点在哪个坐标轴上，要讨论吗？无论是 $ \frac{x^2}{a^2}+\frac{y^2}{b^2}=1(a>b>0) $，还是 $ \frac{y^2}{a^2}+\frac{x^2}{b^2}=1(a>b>0) $，都可统一表示为 $ Ax^2+By^2=1(A>0,B>0,A\neq B) $，故可直接设此统一形式，无需讨论）

设椭圆的标准方程为 $ Ax^2+By^2=1(A>0,B>0,A\neq B) $，因为椭圆经过 $ \left(1,-\frac{\sqrt{3}}{2}\right) $， $ \left(-\sqrt{2},\frac{\sqrt{2}}{2}\right) $两点，

所以 $ \begin{cases}A\cdot1^2+B\cdot\left(-\frac{\sqrt{3}}{2}\right)^2=1\\A\cdot(-\sqrt{2})^2+B\cdot\left(\frac{\sqrt{2}}{2}\right)^2=1\end{cases} $，从而 $ \begin{cases}A+\frac{3}{4}B=1\\2A+\frac{1}{2}B=1\end{cases} $，解得： $ A=\frac{1}{4} $， $ B=1 $，故椭圆的标准方程为 $ \frac{x^2}{4}+y^2=1 $。

【反思】求椭圆的标准方程，若能判断焦点在哪个坐标轴，则直接设对应的标准方程，再结合已知条件求解方程中的参数；若不能判断焦点所在的坐标轴，也别急于讨论。例如，对于给出椭圆上两点的情况，就可统一设为  $ Ax^2 + By^2 = 1 $ ( $ A > 0, B > 0, A \neq B $) 这种形式。

## 类型III：由椭圆标准方程求参

【例 10】已知椭圆 $ \frac{x^2}{m} + \frac{y^2}{9} = 1 $的焦点在y轴上，焦距为4，则实数  $ m $ 的值为___.

解析：将所给方程与焦点在 y 轴的椭圆的标准方程  $ \frac{y^2}{a^2} + \frac{x^2}{b^2} = 1 (a > b > 0) $ 比较，即可得到  $ a^2 $ 和  $ b^2 $ 的值，因为  $ \frac{x^2}{m} + \frac{y^2}{9} = 1 $ 的焦点在 y 轴上，所以  $ a^2 = 9 $， $ b^2 = m $，又因为焦距 2c = 4，所以 c = 2，在椭圆中， $ a^2 = b^2 + c^2 $，所以  $ 9 = m + 2^2 $，解得：m = 5。

答案：5
