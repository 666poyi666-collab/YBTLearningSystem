若双曲线的焦点在 x 轴上，则  $ \begin{cases} a^2 = 2m > 0 \\ b^2 = m - 6 > 0 \\ 2m + m - 6 = c^2 = 9 \end{cases} $，无解；

若双曲线的焦点在 y 轴上，则其方程可化为  $ \frac{y^2}{6 - m} - \frac{x^2}{-2m} = 1 $，所以  $ \begin{cases} a^2 = 6 - m > 0 \\ b^2 = -2m > 0 \\ 6 - m + (-2m) = 3^2 \end{cases} $，解得：m = -1；

综上所述，m = -1。

答案：D

【反思】给出双曲线的方程，要确定谁是 $ a^2 $，谁是 $ b^2 $，可先根据焦点所在的坐标轴，把双曲线化为对应的标准方程的形式，再与 $ \frac{x^2}{a^2} - \frac{y^2}{b^2} = 1 (a > 0, b > 0) $或 $ \frac{y^2}{a^2} - \frac{x^2}{b^2} = 1 (a > 0, b > 0) $比较。

【变式2】（多选）若方程 $ \frac{x^2}{4-t}-\frac{y^2}{2t-1}=1 $所表示的曲线为 $ C $，则下列命题正确的是（ ）

A. 曲线 $ C $可能是圆

B. 若 $ t<4 $且 $ t\neq-3 $，则曲线 $ C $为椭圆

C. 若曲线 $ C $为焦点在 $ x $轴上的椭圆，则 $ -3<t<\frac{1}{2} $

D. 若曲线 $ C $为双曲线，则 $ \frac{1}{2}<t<4 $

 $$ x^{2} $$ 

解析：A 项，要使原方程表示圆，则  $ x^2 $ 与  $ y^2 $ 的系数相同且为正数，由此可建立方程求出参数，

若原方程表示圆，则  $ \frac{1}{4-t} = -\frac{1}{2t-1} \Rightarrow t = -3 $，代回原方程整理得： $ x^2 + y^2 = 7 $，该方程表示圆，故 A 项正确；

B 项，要讨论椭圆焦点在哪条坐标轴上吗？不用，椭圆的方程可统一按  $ mx^2 + ny^2 = 1 $ ( $ m > 0, n > 0, m \neq n $) 处理，故将原方程与之比较，即可建立关于  $ t $ 的不等式组，原方程可变形成  $ \frac{1}{4-t}x^2 + \frac{1}{1-2t}y^2 = 1 $，

要使它表示椭圆，应有  $ \frac{1}{4-t} > 0 $， $ \frac{1}{1-2t} > 0 $，且  $ \frac{1}{4-t} \neq \frac{1}{1-2t} $，解得： $ t < \frac{1}{2} $ 且  $ t \neq -3 $，

所以当  $ t < 4 $ 且  $ t \neq -3 $ 时，曲线 C 不一定为椭圆，故 B 项错误；

C 项，已给出是焦点在 x 轴上的椭圆，故将所给方程化为对应的标准方程，比较系数即可，

原方程可化为  $ \frac{x^2}{4-t} + \frac{y^2}{1-2t} = 1 $，若它表示焦点在 x 轴上的椭圆，则  $ 4-t > 1 - 2t > 0 \Rightarrow -3 < t < \frac{1}{2} $，故 C 项正确；

D 项，没规定双曲线焦点所在的坐标轴，可按  $ mx^2 + ny^2 = 1 (mn < 0) $ 统一处理，

要使原方程表示双曲线，应有  $ \frac{1}{4-t} \cdot \frac{1}{1-2t} < 0 $，即  $ (t-4)(2t-1) < 0 $，解得： $ \frac{1}{2} < t < 4 $，故 D 项正确。

答案：ACD
