由所给椭圆的方程可知  $ a^2 = 25 \Rightarrow a = 5 $，

如图，设椭圆的左焦点为  $ F' $，则  $ \triangle ABF $ 的周长  $ L = |AB| + |AF| + |BF| $，

观察发现当直线  $ AB $ 过  $ F' $ 时， $ \triangle ABF $ 的周长容易求出，故考虑分直线  $ AB $ 过点  $ F' $ 和不过  $ F' $ 两种情况讨论，当直线  $ AB $ 过点  $ F' $ 时，如图中蓝线的情况， $ L = |AB| + |AF| + |BF| = |AF'| + |BF'| + |AF| + |BF| = (|AF'| + |AF|) + (|BF'| + |BF|) = 2a + 2a = 4a = 20 $；

当直线 AB 不过点  $ F^{\prime} $ 时，如图中黑线的情况，

在$\triangle ABF'$中，由两边之和大于第三边，$|AF'| + |BF'| > |AB|$，即$|AB| < |AF'| + |BF|$。所以$L = |AB| + |AF| + |BF| < |AF'| + |BF'| + |AF| + |BF| = (|AF'| + |AF|) + (|BF'| + |BF|)$，$2a + 2a = 4a = 20$；综上所述，$\triangle ABF$的周长的最大值为20。

答案：20

【反思】从上面三道题可以看出，涉及椭圆上的动点与焦点之间距离的最值问题，常用的思路是联系椭圆定义和有关几何性质（如三角形两边之和大于第三边、两边之差小于第三边等）处理，所以当题干只提及了一个焦点时，一定别忘了取出另一个焦点来联合分析。
