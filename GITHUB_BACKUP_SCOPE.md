# GitHub Backup Scope

This private repository preserves the 一本通 learning-system source and current chapter 1-2 delivery.

Included:

- `data/` packets, course transcripts, OCR text, image sidecars, bridge lessons, and course catalog
- `reports/` source bindings, section deliveries, acceptance reports, and final learner-facing Markdown/HTML
- `scripts/`, `tests/`, `ybt_learning/`, manifests, and project documentation
- `codex-skill/ybt-all-chapters-learning-path/`, the reusable Codex skill

Excluded by `.gitignore`:

- `tmp/`, Python caches, virtual environments, editor metadata
- Credential and secret-like local files
- The original `Downloads/课程合集` video files; use the course catalog and transcript hashes to restore or re-download them separately
