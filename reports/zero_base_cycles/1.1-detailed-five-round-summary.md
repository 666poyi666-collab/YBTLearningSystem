## 方法模型

1. **相等、相反与共线向量判定**：长方体、平行六面体中枚举或判断方向关系。步骤：同时检查方向与模 -> 统一起点或平移 -> 用倍数关系完成共线判定。
2. **线性运算与基底拆分**：目标向量不能直接计算。步骤：选公共起点和基向量 -> 按路径或中点关系拆分 -> 合并系数并回译几何对象。
3. **共线、共面与系数和**：证明三点共线、四点共面或判断倍面。步骤：写成同一基底的线性组合 -> 共线检查二维系数和 -> 共面检查三维仿射系数和为1。
4. **等值面末减出**：多个点由同一组基向量表示并判断所在倍面或连线方向。步骤：先求各点系数和 -> 相减得到连线向量系数和 -> 用倍面差解释结果。
5. **空间坐标法**：可建系图形中的长度、垂直和夹角。步骤：建系并标点 -> 写方向向量 -> 点乘或模长计算 -> 按题目角度范围检查绝对值。
6. **数量积与投影**：求夹角、垂直、投影向量或投影长度。步骤：区分向量与标量 -> 使用点积定义或投影公式 -> 检查分母、方向符号和夹角范围。
7. **极化恒等式与最值**：数量积目标可转成和差向量或中点距离。步骤：展开模长平方 -> 选择和式或差式 -> 写可行域与等号条件 -> 回代几何对象。
8. **三角形重心向量**：重心、中线或三顶点等权表示。步骤：先写中点向量 -> 用2:1定比分点 -> 整理成三顶点位置向量平均 -> 换中线复核。
9. **二面角合法截面**：求二面角或面面角。步骤：在公共棱取同一点 -> 两半平面内分别作垂线 -> 取两射线夹角 -> 用法向量时判断等角或补角。
10. **仿射参数求交与同参截线**：两条直线交于三角形两边并需证明截线平行。步骤：为同一交点写两套参数表示 -> 在同一基底逐项比较 -> 统一方向比较两个分点参数 -> 补查退化与线面位置条件。
11. **正数乘积固定时的和最值**：几何约束化为两个正数乘积固定。步骤：先验证正数和定积 -> 由平方非负推出下界 -> 检查等号候选和几何定义域。
12. **外接球与点面距离**：球心、等距约束或点到平面距离。步骤：利用对称性缩减未知量 -> 用等距平方差消去半径 -> 回代关键顶点 -> 再计算法向量投影距离。
